## Paper
Title: The Economic Journal, 132 (August), 2290–2307 https://doi.org/10.1093/ej/ueab105 C⃝The Author(s) 2021. Published by Oxford University Press. All rights
Methodology: - **Data and sample:** The paper pools student-level PISA data from 7 waves (2000–2018) and merges it with country-level preference measures from the Global Preference Survey (GPS; Falk et al., 2018; about 1,000 respondents per country, surveyed in 2012). The baseline cross-country sample is the 49 countries that appear in both PISA and the GPS: 1,992,276 students in 263 country-by-wave cells. The migrant sample drops the 2000 wave because it lacks country of origin. It has 80,398 migrant students (145,506 under a wider definition) from 58 origin countries with GPS data, living in 48 residence countries.
- **Preprocessing:** The GPS patience and risk-taking measures are each built from one qualitative survey item and one hypothetical choice scenario, weighted using the GPS's validation exercise. Each preference domain is z-standardised within the relevant analytical sample and then collapsed to country means. The paper reports a country-level patience–risk correlation of 0.358. PISA scores are divided by 100, so the outcome is in student-level standard deviations (raw PISA score/100). The outcome itself is not otherwise standardised, so coefficients read as SD of achievement per 1 SD of a country preference. Imputation dummies are included for missing controls. Test-taking effort is proxied by item non-response: the share of unanswered questions in the student background questionnaire that follows the test.
- **Baseline specification (Eq. 1; Table 1):** OLS of each student's PISA math score (score/100) on the country's patience and risk-taking: T_ict = β1·Patience_c + β2·Risk_c + α1·B_ict + μ_t + ε_ict.
  - Controls B: student gender, age and migration status, plus imputation dummies and wave fixed effects μ_t. There are no country fixed effects.
  - Preferred spec, Table 1 col 3: Patience 1.226 (SE 0.132), Risk-taking −1.241 (SE 0.184), R² 0.198, N = 1,992,276, 49 countries.
  - Other columns:
    - cols 1–2 enter each preference alone (0.917 and −0.482);
    - col 4 adds the other four GPS preferences (positive and negative reciprocity, altruism, trust);
    - cols 5–6 split natives (N = 1,751,822; 1.296/−1.320) from migrants, meaning both parents born abroad (N = 192,736; 0.702/−0.370);
    - cols 7–8 add individual item non-response and the country-mean item non-response.
  - A country-level regression of pooled mean math scores on the two preferences gives R² = 0.672 (Figure 1).
- **Weighting and inference:** All regressions are weighted by students' sampling probabilities within countries and give each country equal weight. Standard errors are robust and clustered at the country level (49 clusters) in the cross-country analysis.
- **Migrant identification (Eq. 2; Table 2):** Each migrant student is assigned the preferences of their country of origin: T_ioct = δ1·Patience_o + δ2·Risk_o + γ1·B_ioct + θ_c×μ_t + ε_ioct.
  - Fixed effects: 180 residence-country-by-wave fixed effects. Controls: gender, age, a dummy for OECD country of origin, and imputation dummies.
  - Sample: students whose parents were both born outside the testing country. First-generation migrants are assigned their country of birth; second-generation migrants are assigned the father's country of origin. Waves 2003–2018.
  - Standard errors are clustered by country of origin (58 clusters).
  - Preferred spec, Table 2 col 3: Patience 0.931 (SE 0.116), Risk −0.294 (SE 0.122), R² 0.275.
  - Other columns:
    - col 4 adds the other four GPS preferences;
    - cols 5–7 add item non-response (individual, and the country-of-origin mean);
    - cols 8–9 split by whether the student speaks the residence-country language at home (N = 48,556) or another language (N = 24,520).
- **Selectivity robustness (Table 3):** Each column adds one check to the migrant model:
  - continent-of-origin fixed effects;
  - the within-origin-country SDs of patience and risk-taking from individual GPS data;
  - geographic distance between the most populous cities, in 1,000 km (Mayer–Zignago);
  - interactions of each preference with the cultural distance between residence and origin (demeaned absolute preference differences);
  - a migrant schooling-selectivity percentile, i.e. where migrants' educational attainment falls in the origin country's distribution, measured for each residence country.

  The appendix also reports subgroups (OECD vs non-OECD countries, science and reading scores, first- vs second-generation migrants, age at migration, alternative migrant definitions) and alternative preference measures from the WVS and Hofstede.
- **Channels (Table 4):** Country-level OLS (N = 49, robust SEs) of four aggregated proximate-input indices (family, school, institutional, residual) on patience and risk-taking. Upper-bound estimates build the input aggregation without the preference variables; lower-bound estimates include them.
- **No machine-learning protocol:** There is no train/test split, cross-validation or hyperparameter tuning. Evaluation rests on coefficient size, significance (\*\*\*1%, \*\*5%, \*10%), R², and tests of differences between subsamples.

get_header <- function(csv, dta) {
  h <- tryCatch(names(fread(csv, nrows = 0, showProgress = FALSE)), error = function(e) NULL)
  src <- "csv"
  if (is.null(h) || length(h) == 0) {

    src <- "dta"

read_cols <- function(csv, dta, cols, src) {
  d <- NULL

fill_control <- function(d, v) {
  # fill missing control values with mean; add/augment imputation dummy
  if (!v %in% names(d)) return(character(0))
  d[, (v) := num(get(v))]
  imv <- paste0("im", v)
  miss <- is.na(d[[v]])
  if (imv %in% names(d)) {
    d[, (imv) := num(get(imv))]
    d[is.na(get(imv)), (imv) := 0]
    if (any(miss)) d[miss, (imv) := 1]
  } else if (any(miss)) {
    d[, (imv) := as.numeric(miss)]
  }
  if (any(miss)) d[miss, (v) := mean(d[[v]], na.rm = TRUE)]
  out <- v
  if (imv %in% names(d) && length(unique(d[[imv]])) > 1) out <- c(out, imv)
  out
}

prep_outcome <- function(d) {

  d
}

make_weights <- function(d, wcol, ctry) {
  if (!is.na(wcol) && wcol %in% names(d)) {
    d[, w0 := num(get(wcol))]
  } else {
    d[, w0 := 1]
  }
  d[is.na(w0) | w0 <= 0, w0 := NA_real_]
  # sampling weights normalised so that each country receives equal total weight
  d[, w := w0 / sum(w0, na.rm = TRUE), by = ctry]
  d[, w := w * 1000]
  d
}

}

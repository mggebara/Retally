Block randomization was stratified on (i) geographic location, (ii) treatment status in the 2016 campaign and (iii) the chief's past tax-collection experience. The randomization was run 100 times and the run with the minimum t-statistics on balance checks across eight neighborhood-level variables was kept (Banerjee et al. 2017). The main estimator is OLS comparing Local to Central. Analyses use de facto assignment: one CXL neighborhood received Local by mistake.

This is a linear probability / levels specification with no logs and no standardization. The headline β is in percentage points of compliance, or Congolese francs (CF) of revenue per property.

Secondary outcomes include bribes, assessment accuracy, exemptions, visits, tax morale and trust. These come from the midline survey (36,130 complete; every property, 2–4 weeks after collection) and the endline survey (3,893 baseline respondents re-tracked Mar–Sep 2019; baseline 4,246 households, about 12 per neighborhood).

find_key <- function(a, b) {
  ex <- c('a7', 'stratum', 'commune', 'treatment', 'house', 'exempt', 'status', 'time', 'pilot', 'rate',
          'paid', 'amount', 'month', 'first', 'present', 'tot_complete', 'date', 'today', 'rate_assigned')
  common <- setdiff(intersect(names(a), names(b)), ex)
  best <- NULL; bs <- 0
  for (k in common) for (comb in c(FALSE, TRUE)) {
    if (comb && !('a7' %in% names(a) && 'a7' %in% names(b))) next
    va <- chr(a[[k]]); vb <- chr(b[[k]])
    ok <- !is.na(va) & va != '' & va != 'NA'
    if (sum(ok) < 0.5 * nrow(a)) next
    ka <- if (comb) paste(a$a7, va) else va
    kb <- if (comb) paste(b$a7, vb) else vb
    uq <- length(unique(ka[ok])) / sum(ok)
    if (uq < 0.9) next
    ov <- mean(kb %in% ka[ok])
    if (ov > bs + 0.01) { bs <- ov; best <- list(k = k, comb = comb, ov = ov) }
  }
  if (!is.null(best)) cat(sprintf('[key] %s comb=%s overlap=%.3f\n', best$k, best$comb, bs)) else cat('[key] none found\n')
  best
}

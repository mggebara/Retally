Title: American Economic Review 2022, 112(3): 1–36
Methodology: - **Design / estimation method:** Cluster-randomized policy experiment embedded in Kasaï-Central's 2018 property tax campaign in Kananga (DRC). 356 neighborhoods (45,162 registered properties) were assigned to Central (state collectors; 110 neighborhoods / 14,489 properties), Local (city chiefs; 111 / 14,383), Central + Local Information (CLI; 80 / 9,422), Central X Local (CXL; 50 / 6,071) and pure Control (declarative system; 5 / 797). Block randomization was stratified on (i) geographic location, (ii) treatment status in the 2016 campaign and (iii) the chief's past tax-collection experience. The randomization was run 100 times and the run with the minimum t-statistics on balance checks across eight neighborhood-level variables was kept (Banerjee et al. 2017). The main estimator is OLS comparing Local to Central. Analyses use de facto assignment: one CXL neighborhood received Local by mistake.
- **Estimating equation (eq. 1):** y_ijkt = β0 + β·Local_jkt + X_ijk Γ + α_k + θ_t + ε_ijkt, with i = household/property, j = neighborhood, k = randomization stratum, t = campaign wave. The key regressor is the Local treatment dummy, with Central as the omitted category; other arms enter as separate treatment indicators where relevant. This is a linear probability / levels specification with no logs and no standardization. The headline β is in percentage points of compliance, or Congolese francs (CF) of revenue per property.
- **Outcomes and units:** The main outcomes come from administrative data: handheld receipt-printer payment records matched by tax ID to the property register for the universe of registered properties. They are (a) tax compliance, a 0/1 indicator for paying the 2018 property tax, and (b) revenue per property in CF. Headline result (Table 4, col. 2): compliance was 9.5% in Local vs 6.3% in Central, a +3.2 pp effect, worth +79.6 CF per property (+44% revenue). Secondary outcomes include bribes, assessment accuracy, exemptions, visits, tax morale and trust. These come from the midline survey (36,130 complete; every property, 2–4 weeks after collection) and the endline survey (3,893 baseline respondents re-tracked Mar–Sep 2019; baseline 4,246 households, about 12 per neighborhood).
- **Fixed effects and controls (preferred spec):** Randomization stratum fixed effects α_k, plus time fixed effects θ_t for campaign waves. These net out 2018 compliance trends and time imbalance from the staggered rollout. The covariates X_ijk are only dummies for house type (low- vs high-value property band). The preferred specification for tax outcomes is Table 4, column 2 (with wave FE); column 1 omits the time FE. Endline-survey outcomes exclude the time FE and the house-type dummies, because merging with the register would shrink the sample.
- **Standard errors:** Clustered at the neighborhood level (356 clusters). Balance tests (Table 3) use the same stratum FE and neighborhood clustering, with Central omitted and pure Control excluded. Joint F-tests for bilateral comparisons are in Appendix Table A2.
- **Sample restrictions:** Of 364 neighborhoods, 8 used in a logistics pilot were excluded, leaving 356; the commune of Nganza is excluded because of the 2017 conflict. The 285 very-high-value villas are outside the campaign and excluded. The main Local-vs-Central comparison excludes pure Control neighborhoods. The default tax-outcome sample includes exempt properties. Midline data are missing for 21% of registered properties (no adult present, or exempt property types not surveyed); this attrition is balanced across arms. Baseline-to-endline attrition was 8.3%, with 12% of endline respondents replaced by another household member.
- **Robustness (Table 4 and appendix):**
  - Data collapsed to the neighborhood level (col. 3).
  - Property-value-band fixed effects added (col. 4).
  - Exempt properties excluded (col. 5; the effect rises to 4.0 pp).

  - Controls for, and interactions with, household-level cross-randomized collector wage (30% piece rate vs flat 750 CF) and tax-rate abatements (App. Table A6).
  - Alternative covariate vectors from the pre-analysis plan, including years of education (the one imbalanced baseline variable); also dropping the misassigned neighborhood (App. Table A7).
  - Controlling for collector characteristics (App. Table A8).
- **Mechanism tests and evaluation:** CLI vs Central tests whether local information explains the effect: chiefs rated each household's ability and willingness to pay on 3-point scales before state collectors made follow-up visits (CLI raised compliance by +2.2 pp). Further tests compare collection during the linear registration stage (when targeting is neutralized) with collection afterwards, examine visit counts and the characteristics of visited households, and check heterogeneity by chief knowledge (quiz), trust and power. Cost-effectiveness and a bribe-weighting welfare calculation follow. This is causal-inference evaluation, with no train/test split or cross-validation.

arm_of <- function(x) {
  if (inherits(x, "haven_labelled")) {
    lab <- as.character(haven::as_factor(x, levels = "labels"))
  } else lab <- as.character(x)
  l <- tolower(lab)
  out <- rep(NA_character_, length(l))
  out[grepl("control|declar|pure", l)] <- "Control"
  out[grepl("central", l)] <- "Central"
  out[grepl("local", l)] <- "Local"
  out[grepl("cxl|central x local|central_x_local|central-x-local|x local| x |both", l)] <- "CXL"
  out[grepl("info|cli", l)] <- "CLI"
  out
}

arm_by_count <- function(code) {
  # fallback when treatment codes are unlabelled: map by neighborhood counts
  v <- num(code)
  tb <- sort(table(v))
  out <- rep(NA_character_, length(v))
  if (length(tb) < 4) return(out)
  vals <- as.numeric(names(tb))
  cnt <- as.numeric(tb)
  m <- c()
  m[as.character(vals[which.min(abs(cnt - 5))])] <- "Control"
  m[as.character(vals[which.min(abs(cnt - 50))])] <- "CXL"
  m[as.character(vals[which.min(abs(cnt - 80))])] <- "CLI"
  big <- vals[order(-cnt)][1:2]
  big <- sort(big)
  m[as.character(big[1])] <- "Central"
  m[as.character(big[2])] <- "Local"
  out <- unname(m[as.character(v)])
  out
}

to_bin <- function(x) {
  lab <- NULL
  if (inherits(x, "haven_labelled")) lab <- attr(x, "labels")
  v <- num(x)
  v[!is.na(v) & v < 0] <- NA
  if (!is.null(lab)) {
    nm <- tolower(names(lab))
    yes <- lab[grepl("^yes|^oui", nm)]
    no <- lab[grepl("^no$|^no |^no,|^non", nm)]
    if (length(yes) && length(no)) {
      return(ifelse(v %in% yes, 1, ifelse(v %in% no, 0, NA)))
    }
  }
  u <- unique(na.omit(v))
  if (all(u %in% c(0, 1))) return(v)
  if (all(u %in% c(1, 2))) return(ifelse(is.na(v), NA, ifelse(v == 1, 1, 0)))
  ifelse(is.na(v), NA, as.numeric(v > 0))
}

to_date <- function(x) {

    d <- suppressWarnings(as.Date(x))
    if (all(is.na(d))) d <- suppressWarnings(as.Date(x, format = "%d%b%Y"))
    return(d)
  }
  v <- num(x)
  if (all(is.na(v))) return(as.Date(v, origin = "1960-01-01"))
  if (median(v, na.rm = TRUE) > 1e8) return(as.Date(as.POSIXct(v / 1000, origin = "1960-01-01", tz = "UTC")))

}

make_period <- function(armA, armB) {
  s <- nb[nb$arm %in% c(armA, armB) & !is.na(nb$start), ]
  fa <- min(s$start[s$arm == armA]); fb <- min(s$start[s$arm == armB])
  la <- max(s$start[s$arm == armA]); lb <- max(s$start[s$arm == armB])
  st <- fa + as.numeric(fb - fa) / 2
  en <- la + as.numeric(lb - la) / 2
  st <- as.Date(floor(as.numeric(st)), origin = "1970-01-01")
  en <- as.Date(ceiling(as.numeric(en)), origin = "1970-01-01")
  br <- seq(st, en + 70, by = "2 months")
  p <- findInterval(as.numeric(nb$start), as.numeric(br))
  p[is.na(nb$start) | nb$start < st | nb$start > en] <- NA
  msg("periods", armA, armB, as.character(st), as.character(en)); msg(capture.output(print(table(p[nb$arm %in% c(armA, armB)], useNA = "ifany"))))
  setNames(p, nb$a7)
}

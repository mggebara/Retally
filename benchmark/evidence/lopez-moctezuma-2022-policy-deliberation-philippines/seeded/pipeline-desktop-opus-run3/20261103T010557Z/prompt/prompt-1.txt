## Paper Information
Title: Policy Deliberation and Voter Persuasion:
Abstract (first 500 chars): In a randomized experiment in cooperation with two national parties competing in a congressional election
in the Philippines, we estimate the causal effect on voting behavior of a town-hall style campaign in which candidates
discuss their campaign platform with small groups of citizens. Keeping the parties’ platform fixed, we find that town-hall
meetings have a positive effect on parties’ vote shares compared to the status quo, in which voters play a passive role.
Consistent with the parties’ ad
Methodology Summary: - **Design / sample**: Field experiment in the May 13, 2013 Philippine party-list election with two party lists (Akbayan, feminist platform; Umalab Ka, urban-poor platform). Two-stage cluster sampling: 7 of 17 NCR municipalities and 6 of 90 Calabarzon municipalities (13 municipalities); in each, 3 barangays drawn at random, 1 assigned to treatment (2–3 town-hall meetings of ~40 participants, held Apr 21–May 9) and 2 to control ("business-as-usual" one-way campaign). Barangays within 1.5 km of each other were resampled. Municipalities were randomly assigned to the two party lists. Total 39 barangays (18 Akbayan, 21 Umalab Ka). Noncompliance: treatment was not implemented as assigned in Concepcion Dos (Marikina), Isla (Valenzuela) and San Roque (Louisiana); meetings were held in other barangays instead.

- **Barangay-level ITT (Eq. 1, Table 1)**: OLS of Y_jk = δ_k + β Z_jk + ε_jk, where Y is official COMELEC party-list turnout (% of registered voters) or the vote share of the treating party (% of total party-list votes), in percentage points (levels, not logs, not standardised). Z is the random assignment dummy and δ_k are municipality ("City") fixed effects. Columns: (1) turnout, N=39; (2) pooled vote share, N=39; (3) Akbayan vote share, N=18; (4) Umalab Ka vote share, N=21. Headline ITTs: −4.544, 1.096, 1.955, 0.360. Control means: 65.040, 2.397, 4.897, 0.253. R²: .389, .776, .453, .412.

- **CACE (Eq. 2)**: IV/2SLS of Y_jk = λ_k + α T_jk + υ_jk, where actual implementation T_jk is instrumented with assignment Z_jk and municipality FE are included. Compliers exclude the 3 noncomplying barangays. Table 1 CACEs: −5.908, 1.425, 2.606, 0.459.

- **Barangay-level inference**: nonparametric randomization/permutation test (Efron & Tibshirani 1994). Treatment assignment is permuted within municipality to build the null distribution of no effect, giving permutation p-values for the ITT (Table 1: turnout p=.404, pooled vote p=.048, Akbayan p=.087, Umalab Ka p=.141). No conventional SEs are used for the headline barangay estimates. Heterogeneity analysis: (a) treatment × number of registered voters with municipality FE (Fig. 2 left); (b) proportion of meeting attendees, instrumented with assignment, with municipality FE (Fig. 2 right).

- **Individual-level data**: postelection survey run by CPE two weeks after the election, using random-walk/quota sampling (intended 40 per barangay; every 5th household). There are 1,314 respondents. The estimation sample is 1,082 after dropping respondents without a valid turnout response. Municipalities Imus, Pateros and Santa Maria are excluded because they lack both treatment and control survey barangays. Multiple-imputation robustness check in SI Appendix E.

- **Individual-level specifications (Eqs. 3–5)**: linear probability models of turnout / vote for the treating party on assignment Z (ITT) with municipality FE, and IV versions instrumenting T with Z (CACE). SEs are clustered at the barangay level, the level of treatment assignment. Estimates use inverse probability weights to correct oversampling of meeting attendees (weight = ratio of self-reported survey attendees to actual attendees from attendance sheets). Unweighted results in SI Appendix F use permutation inference. Heterogeneity (Eq. 5): Z, X, and Z×X with municipality FE, where X is income (cut at 10,000 pesos), education (primary or less vs. high school or more) or gender. Run separately by party, with ITT and IV-CACE analogues. Robustness to adding pretreatment covariates is in SI Appendix D.

- **Mechanism outcomes (Fig. 5)**: Anderson (2008) approach. Each item is oriented so positive means more agreement, then standardised relative to the control-group mean and s.d. Items are combined into inverse-covariance-weighted summary indices: a gender-discrimination/sexism index from 6 items (Female Rep., Female Pol., Equality, Discrimination, Harassment) and a poverty index from 4 items (Poverty, GAP, CCT, Corruption). ITT and CACE are reported in s.d. units with city FE, barangay-clustered SEs and 95% CIs. Examples: Akbayan gender index ITT 0.45 s.d., CACE 0.67 s.d.; Umalab Ka poverty index ITT 0.13 s.d.

- **Balance / evaluation**: balance on pretreatment official statistics and on survey covariates is checked in SI Appendix B. There is no train/test split or cross-validation, since this is a randomized-experiment causal inference design. Metrics are ITT/CACE point estimates with permutation p-values (barangay level) or clustered-SE 95% CIs (individual level). Relative effects are also reported, e.g. pooled ITT 1.1 pp on a 2.4% base ≈ 46% increase.

## Load aggregate data
load("data_agg.RData")

parties <- as.character(unique(data.all$partytreat))

partynames <- c("Umalab Ka", "Akbayan")

##Tables A1 and A2 in the paper
for (i in 1:length(parties)){

    ## We split the data by party-list
    data.party <- as.tbl(data.all) %>%
        filter(partytreat == parties[i]) %>%
        arrange(city,
                barangay)

    ## Construct table of summary statistics
    turnout.table <- data.frame(city = data.party$city,
                                barangay = data.party$barangay,
                                status = data.party$treatment,
                                turnout.general = data.party$turnout.general,
                                turnout.party = data.party$turnout.party,
                                share.treated = data.party$share.treated)

    turnout.table$status <- ifelse(turnout.table$status == 0,
                                   "Control",
                                   "Treated")

    turnout.table[,4:6] <- round(turnout.table[,4:6], digits = 2)

    ##Summary statistics across barangays
    mean.turnout <- round(colMeans(turnout.table[,4:6], na.rm = TRUE),
                          digits = 2)

    sd.turnout <- round(c(sd(turnout.table$turnout.general, na.rm = TRUE),
                          sd(turnout.table$turnout.party, na.rm = TRUE),
                          sd(turnout.table$share.treated, na.rm = TRUE)),
                        digits = 2)

    turnout.table <- rbind(as.matrix(turnout.table),
                           c("Mean", rep("",2),mean.turnout),
                           c("S.D.", rep("",2),sd.turnout))

    turnout.table[is.na(turnout.table) == 1] <- "-"

    colnames(turnout.table) <- c("City", "Barangay", "Status", "Turnout (National)",
                                 "Turnout (Party-list)", "Vote Share (Treatment)")

    ## Add footnotes
    if(parties[i] == "akbayan"){

        add.to.row <- list(pos = list(nrow(turnout.table)), command = NULL)

        command <- paste0("\\hline\n",
                          "\\multicolumn{", ncol(turnout.table),"}{l}",
                          "{\\footnotesize Note: No available general election figures for the barangays of Cabooan, Zone VI and Hagonoy.}\n")

        add.to.row$command <- command

    } else {

        add.to.row <- NULL
    }

    print.xtable(xtable(turnout.table,
                 digits = 3,
                 caption = paste("Turnout for the National and Party-List Elections (", partynames[i]," Barangays)", sep = ""),
                 align = c("l","l","l","l","c","c","c"),
                 label = paste("turnout_", parties[i],sep = "")),
                 file = paste0(output,"/summary_agg_",parties[i],".txt"),
          include.rownames = FALSE,
          hline.after = c(-1,0,nrow(turnout.table) - 2),
          add.to.row = add.to.row,
          size = "footnotesize")

}

## Load aggregate data at the barangay level
load("data_agg.RData")
## Balance variables
vars <- c("reg.pop.thousand",
          "female.pop",
          "urban")

## Use F-test to assess the null hypothesis that the covariates predict random assignment (Z) no better than would be expected by chance

assignment <- data.all$assignment

cluster <- data.all$barangay
block <- data.all$city

perms <- genperms(assignment,
                  blockvar=block,
                  clustvar=cluster)

numiter <- ncol(perms)
probs <- genprobexact(assignment,
                      blockvar = block,
                      clustvar=cluster)  # subjects are clustered by precinct

covs <- as.matrix(data.all[,c("reg.pop.thousand",
                              "female.pop",
                              "urban")])

weights <- assignment/probs + (1-assignment)/(1-probs)
Fstat <- summary(lm(assignment ~ covs, weights = weights))$fstatistic[1]   # F-statistic from actual data
Fstatstore <- rep(NA,numiter)
for (n in 1:numiter) {
    probs <- genprobexact(perms[,n],
                          blockvar = block,
                          clustvar=cluster)
    weights <- perms[,n]/probs + (1-perms[,n])/(1-probs)
    Fstatstore[n] <- summary(lm(perms[,n]~covs, weights = weights))$fstatistic[1]   # F-statistic under the null of random assignment of Z
}

pvalue <- mean(Fstatstore >= Fstat)
kernel.null <- density(Fstatstore)


## Figure B.1
pdf(paste(output,"/fstatcov.pdf",sep=""))
plot(kernel.null,
     xlim = c(min(kernel.null$x), max(kernel.null$x)),
     ylim = c(min(kernel.null$y), max(kernel.null$y)),
     main = "",
     xlab = "F-statistic(%)",
     ylab = "Frequency",
     )
polygon(kernel.null, col="blue", border="blue")
abline(v=Fstat, lty = 2, col = "red")
text(Fstat + 1,
     max(kernel.null$y),
     paste("Fstat = ", round(Fstat, digits = 2), sep = ""),
     col = "red")
mtext(paste("p-value=", round(pvalue, 4)), 3)

dev.off()

## We store the  output in the following lists
reglist <- atelist  <- coeflist <- plist <- p_rilist <- vector( "list", length(vars))

## We estimate the ATE of each pre-treatment variable on electoral returns
for (i in 1:length(vars)){

    data.reg <- data.all[complete.cases(data.all[vars[i]]),]

    assignment <- data.reg$assignment
    treatment <- data.reg$treatment
    att.prop <- data.reg$att.prop
    att.prop.turn <- data.reg$att.prop.turn
    outcome <- data.reg[,vars[i]]
    cluster <- data.reg$barangay
    block <- data.reg$city
    ## Control for cluster fixed effects
    X <- dummy("city", data.reg)[,-1]
    ## Generate all possible permutations
    perms <- genperms(assignment,
                      blockvar=block,
                      clustvar=cluster)

    ## Compute probability of treatment
    probs <- genprobexact(assignment,
                          blockvar=block,

    ## Compute weights given assignment prob

                  assignment,
                  X = X,
                  prob=probs)

                       weights = weights)

    plist[[i]] <- summary(reglist[[i]])$coefficients[,4]

}

    if (vars[i] %in% c("turnout.party",
                       "share.treated")){
        data.reg <- data.all[complete.cases(data.all[vars[i]]),]
    } else {
        if (vars[i] == "share.akbayan") {
            data.reg <- data.all[complete.cases(data.all[vars[i]]) & data.all$partytreat == "akbayan",]
        } else {

        }

    treatment <- data.reg$treatment

    att.prop.turn <- data.reg$att.prop.turn
    outcome <- data.reg[,vars[i]]
    cluster <- data.reg$barangay
    block <- data.reg$city
    X <- dummy("city", data.reg)[,-1]
    ## Generate all possible permutations
    set.seed(1983)
    perms <- genperms(assignment,
                      blockvar=block,
                      clustvar=cluster,
                      maxiter = 50000)

    ## Compute probability of treatment
    probs <- genprobexact(assignment,
                          blockvar=block,
                          clustvar=cluster)

    weights <- assignment/probs + (1-assignment)/(1-probs)

    ## Estimate the ATE
    atelist[[i]] <- estate(outcome,
                           assignment,
                           X = X,
                           prob=probs)


    ## Estimate the CACE
    cacelist[[i]] <- estlate(outcome,

                             assignment,
                             X = X,
                             prob=probs)
    ## Store results over these regressions

    ## We substitute the ri ate and pvalue

p.value <- function(observed.stat, perms, Y1, Y0) {
    sims <- ncol(perms)
  sim.stats <- numeric(sims)

  for (i in 1:sims) {
    t.sim <- perms[,i]  # Simulate random assignment
    Y.sim <- t.sim * Y1  +  (1 - t.sim) * Y0
    sim.stats[i] <- abs.diff.var(t.sim, Y.sim)
  }

  mean(sim.stats >= observed.stat)

# See: Thompson (2006), Cameron, Gelbach and Miller (2006) and Petersen (2010).
# and Gow, Ormazabal, and Taylor (2010) for more discussion of this code
# and two-way cluster-robust standard errors.

# The arguments of the function are data, fitted model, cluster1 and cluster2
# You need to install packages `sandwich' by Thomas Lumley and Achim Zeileis and
# `lmtest' by Torsten Hothorn, Achim Zeileis, Giovanni Millo and David Mitchell.
# (For example, type install.packages("sandwich") on the R console.)
varcov.cluster <- function(data, fm, cluster1, cluster2=NULL) {

  require(sandwich)
  require(lmtest)

  # Calculation shared by covariance estimates
  est.fun <- estfun(fm)
  # est.fun <- sweep(fm$model,MARGIN=2,fm$residuals,`*`)

  # Need to identify observations used in the regression (i.e.,
  # non-missing) values, as the cluster vectors come from the full
  # data set and may not be in the regression model.
  # I use complete.cases following a suggestion from
                                        # Francois Cocquemas <francois.cocquemas@gmail.com>
  names.nw <- names(fm$model)[-which(names(fm$model) == "(weights)")]
  inc.obs <- complete.cases(data[,names.nw])
  # inc.obs <- !is.na(est.fun[,1])
  # est.fun <- est.fun[inc.obs,]

  # Shared data for degrees-of-freedom corrections
  N  <- dim(fm$model)[1]
  NROW <- NROW(est.fun)
  K  <- fm$rank

  # Calculate the sandwich covariance estimate
  cov <- function(cluster) {
    cluster <- factor(cluster)

    # Calculate the "meat" of the sandwich estimators
    u <- apply(est.fun, 2, function(x) tapply(x, cluster, sum))
    meat <- crossprod(u)/N

    # Calculations for degrees-of-freedom corrections, followed
    # by calculation of the variance-covariance estimate.
    # NOTE: NROW/N is a kluge to address the fact that sandwich uses the
    # wrong number of rows (includes rows omitted from the regression).
    M <- length(levels(cluster))
    dfc <- M/(M-1) * (N-1)/(N-K)
    dfc * NROW/N * sandwich(fm, meat=meat)
  }

  # Calculate the covariance matrix estimate for the first cluster.
  cluster1 <- data[inc.obs,cluster1]
  cov1  <- cov(cluster1)

  if(is.null(cluster2)) {
    # If only one cluster supplied, return single cluster
    # results
    return(cov1)
  } else {
    # Otherwise do the calculations for the second cluster
    # and the "intersection" cluster.
    cluster2 <- data[inc.obs,cluster2]
    cluster12 <- paste(cluster1,cluster2, sep="")

    # Calculate the covariance matrices for cluster2, the "intersection"
    # cluster, then then put all the pieces together.
    cov2   <- cov(cluster2)
    cov12  <- cov(cluster12)
    covMCL <- (cov1 + cov2 - cov12)

    # Return the output of coeftest using two-way cluster-robust
    # standard errors.
    return(covMCL)
  }
}

wmean <- function(y, sigma, k){
    one <- rep(1,k)
    s <- solve(t(one) %*% solve(sigma) %*% one) %*% (t(one) %*% solve(sigma) %*% y)
    return(s)
}

numextract <- function(string){
  str_extract(string, "\\-*\\d+\\.*\\d*")
}

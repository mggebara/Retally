Methodology Summary: # Methodology Summary

**Research design / identification strategy:**
- Natural experiment exploiting the 1926 Air Corps Act, which gave US airframe producers de facto IP protection (via negotiated procurement contracts) while leaving aero-engine IP protection unchanged. The authors use a pre/post 1926 comparison within the US, plus a difference-in-differences-style comparison between the US and the UK (and, where data allow, Germany, Italy, Japan).

**Sample and data construction:**
- Near-universe of military airframe models and matched aero-engines, 1918–1935, hand-collected from aircraft reference books. Observation = a new airframe model (including sub-variants, e.g., PW-9A, PW-9B) or engine design.
- Analysis restricted primarily to **fighters and bombers**, because these are high-performance segments most distinct from civilian aircraft and where performance metrics are most meaningful. Other segments (e.g., reconnaissance) relegated to the appendix.

**Outcome variables (direct performance measures, used instead of patents since patents are endogenous to the IP regime):**
- Airframes: **wing load** (gross weight / wing area) — preferred measure; also **maximum speed** (mph).
- Aero-engines: **horsepower / engine weight**, **horsepower / displacement (liters)**, **horsepower / frontal area (sq. in.)**.
- Supplementary outcomes: development of new liquid-cooled engines, vintage gap between engines and the airframes they power, and merger activity between airframe and engine firms.

**Specification / estimation:**
- Primary evidence is graphical (time-series plots of performance metrics for US vs. comparison countries, pre- vs. post-1926). The paper does not describe a formal regression with fixed effects, clustered SEs, or a headline coefficient of interest in the excerpt provided — identification rests on visual pre/post and US-vs-UK comparisons around the 1926 break.
- Theoretical model: static one-period partial-equilibrium model with Bertrand competition (no IP) vs. Nash-in-Nash monopolist–monopsonist bargaining (with IP); used to derive testable predictions (Propositions 1–4) rather than to structurally estimate.

**Variables excluded due to data limitations:**
- Airframe and engine prices, and firm profits (not consistently available), so analysis relies on physical performance characteristics.

**Robustness / alternative-mechanism checks discussed:**
- Rule out confounds from the 1925 Air Mail Act and 1926 Air Commerce Act by noting military dominated high-performance segment (military spending $88M vs. civilian $55M, 1926–1936; much higher unit values and horsepower).
- Rule out common technology-frontier shocks via cross-country comparison, aided by the fact that NACA budget growth shows no 1926 break (Appendix Figure B3) and research was internationally disseminated.
- Test merger prediction (Proposition 4) via firm-history analysis of vertical-complement mergers between airframe and engine producers.

cls

**-> Airframes <-***************************************************************

*-------> United States
	
	* Load Data
	import delimited "$aircraft/data/raw/US_data1.csv",clear
	
	* Generate Country Variable
	g country = "United States" 
	label var country "Country"
	
	* Identify Airframe Type Variable
	qui g fighter = (type=="Fighter"|type=="Carrier fighter"|type=="Carrier jet fighter"|type=="Pursuit"|type=="Jet fighter"|type=="Atack") if country == "United States"
	qui g trainer = (type=="Tranining"|type=="Trainer/Observation"|type=="Training"|type=="Tranier"|type=="Tranining"|type=="Primary trainer"|type=="Specialized trainer") if country == "United States"
	qui g bomber = (type=="Bomber"|type=="Bomber floatplane"|type=="Carrier bomber"|type=="Heavy bomber"|type=="Jet Bomber"|type=="Jet Heavy Bomber"|type=="Jet Medium Bomber"|type=="Jet light bomber"|type=="Jet reconnaisance bomber"|type=="Light bomber"|type=="Medium bomber") if country == "United States"
	qui g recon = (type=="Observation" | type=="Observation amphibian" | type=="Observation floatplane" | type=="Observation seaplane" | type=="Observation/bombing" | type=="Reconnaissance")
	drop type
	g type = "fighter" if fighter==1
	replace type = "bomber" if bomber==1
	replace type = "trainer" if trainer==1
	replace type = "recon" if recon==1
	label var type "Type"
	drop fighter bomber trainer recon
	
	* Generate Outcome Variables
	label var maxspeed "Maximum Speed" 
	label var grossweight "Gross Weight"
	label var wing_area "Wing Area"
	label var cruise "Cruise Speed"
	label var climb_ft_per_min "Climb feet per minute"
	label var climb_to_10000 "Climb to 10,000 feet"
	label var ceiling "Ceiling"
	label var range "Range"
	label var endurance "Endurance"
	
	* Generate Other Variables
	label var enginehp "Engine Horsepower"
	label var no_engines "Number of Engines"
	label var count "Count"
	label var year "Year"
	label var company "Company"
	label var location "Location"
	label var model "Model"
															
	* Keep/Order Variables
	keeporder year country type enginehp maxspeed grossweight wing_area maxspeed cruise climb_ft_per_min climb_to_10000 ceiling range endurance count no_engines engine_maker
	
	* Save US Data
	save "$aircraft/data/dta/temp/temp_airframe_us.dta",replace

********************************************************************************

cls
clear all
ssc install keeporder

********************************************************************************

*global aircraft "[ File path here ]"

********************************************************************************
**-> Engines <-*****************************************************************
********************************************************************************

*-------> United States	(Fahey Data)
	
	* Load Data
	import delimited "$aircraft/data/raw/US_data2.csv",clear
	drop source*
	
	* Generate Country Variable
	g country = "United States" 
	label var country "Country"
	
	* Generate Outcome Variables
	g horsepower = normalrating
	replace horsepower = horspoweralternative if horsepower ==.
	label var horsepower "Horsepower"
	g weight = weightdry
	replace weight = weightdryalternative if weight==.
	label var weight "Dry Weight (in lbs)"
	g hp_per_lbs = horsepower/weight
	label var hp_per_lbs "Horsepower per Pound"
	g hp_per_disp = horsepower/pistondisplacementinliters
	label var hp_per_disp "Horsepower per Liter of Piston Displacement"
	g hp_per_disp_rpm = horsepower/(pistondisplacementinliters*revolutionsperminuterpm)
	label var hp_per_disp_rpm "Horsepower per (Liter of Piston Displacement and RPM)"
	
	* Generate Other Variables
	rename yearoffirstusebyarmy year
	label var year "Year"
	rename builder make
	label var make "Make"
	label var model "Model"
	g liquid_cooled = (cooling=="liquid")
	label var liquid_cooled "Liquid Cooled Engine == 1"
	
	* Keep/Order Variables
	keeporder country make model year liquid_cooled hp_per_disp hp_per_lbs hp_per_disp_rpm 

	* Save US Data
	save "$aircraft/data/dta/temp/temp_engine_us_fahey.dta",replace

*-------> United States (Fighter and Bomber Data)
	
	* Load Data
	import delimited "$aircraft/data/raw/US_data1.csv",clear
	replace count = 1 if count==.
	
	* Generate Country Variable
	g country = "United States" 
	label var country "Country"
	
	* Identify Airframe Type Variable
	g fighter = (type=="Fighter"|type=="Carrier fighter"|type=="Carrier jet fighter"|type=="Pursuit"|type=="Jet fighter"|type=="Atack") if country == "United States"
	g bomber = (type=="Bomber"|type=="Bomber floatplane"|type=="Carrier bomber"|type=="Heavy bomber"|type=="Jet Bomber"|type=="Jet Heavy Bomber"|type=="Jet Medium Bomber"|type=="Jet light bomber"|type=="Jet reconnaisance bomber"|type=="Light bomber"|type=="Medium bomber") if country == "United States"
	keep if fighter | bomber
	drop type
	
	* Generate Outcome Variables
	g hp_per_lbs = enginehp/weight
	g hp_per_disp = enginehp/displ
	g hp_per_frontal = enginehp/frontalarea
	g hp_per_disp_rpm = enginehp/(displ*rpm)
	
	* Generate Cooling Variable
	g liquid_cooled = (cooling=="liquid")
	
	* Drop Missing
	drop if hp_per_lbs==. & hp_per_disp==. & hp_per_frontal==. & hp_per_disp_rpm==.
	
	* Collapse
	collapse (mean) hp_* (sum) count (min) year=firstyear (max) liquid_cooled, by(country engine_maker engine_type enginehp disp)
	
	* Keep/Order Variables
	keeporder country engine_make engine_type year count hp_* liquid
	sort country engine_make engine_type year

	* Save US Data
	save "$aircraft/data/dta/temp/temp_engine_us.dta",replace
	
*-------> United Kingdom (Fighter and Bomber Data)
	
	* Load Data
	import delimited "$aircraft/data/raw/UK_data.csv",clear
	rename (engine_maker engine_type) (engine_maker engine_type)
	replace count = 1 if count==.
	
	* Generate Country Variable
	g country = "United Kingdom" 
	label var country "Country"
	
	* Identify Airframe Type Variable
	g fighter = (type=="Fighter"|type=="Carrier fighter") if country == "United Kingdom"
	g bomber = (type=="Bomber"|type=="Carrier torpedo bomber"|type=="Dive bomber"|type=="Torpedo bomber"|type=="Reconnaisance and bomber seaplane") if country == "United Kingdom"
	keep if fighter | bomber
	drop type
	
	* Generate Outcome Variables
	g hp_per_lbs = enginehp/weight
	g hp_per_disp = enginehp/displ
	g hp_per_frontal = enginehp/frontalarea
	g hp_per_disp_rpm = enginehp/(displ*rpm)

	* Generate Cooling Variable
	g liquid_cooled = (cooling=="W")
	
	* Drop Missing
	drop if hp_per_lbs==. & hp_per_disp==. & hp_per_frontal==. & hp_per_disp_rpm==.

	* Collapse
	collapse (mean) hp_* (sum) count=count (min) year=firstyear (max) liquid_cooled, by(country engine_maker engine_type engine_hp enginehp)
	
	* Keep/Order Variables
	keeporder country engine_make engine_type year count hp_* liquid
	sort country engine_make engine_type year

	* Save US Data
	save "$aircraft/data/dta/temp/temp_engine_uk.dta",replace
	
*-------> Italy
	
	* Load Data
	import delimited "$aircraft/data/raw/JANES_engine_data.csv", clear
	keep if country=="Italy" 
	drop country
	
	* Generate Country Variable
	g country = "Italy"
	label var country "Country"
	
	* Generate Outcome Variables
	rename hp_per_displ hp_per_disp
	label var hp_per_disp "Horsepower per Liter of Piston Displacement"
	rename hp_per_lbs hp_per_lbs
	label var hp_per_lbs "Horsepower per Pound"
	g hp_per_disp_rpm = hp_per_disp*(1/rpm)
	label var hp_per_disp_rpm "Horsepower per (Liter of Piston Displacement and RPM)"

	* Generate Other Variables
	rename company engine_make 
	label var engine_make "Make"
	rename engine engine_type
	label var engine_type "Model"
	rename yr_introduced year

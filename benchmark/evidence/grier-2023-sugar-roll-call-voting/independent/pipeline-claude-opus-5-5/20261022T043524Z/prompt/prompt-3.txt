## Paper
Title: American Political Science Review (2023) 117, 1, 340–346
Methodology: - **Design and estimator:** The authors pool two near-identical House roll calls on anti-sugar-subsidy amendments as repeated votes on one issue.
  - The 2013 vote was the Pitts amendment (H.Amdt. 227), on 6/20/2013, which failed 206–221.
  - The 2018 vote was the Foxx amendment (H.Amdt. 605), on 5/17/2018, which failed 137–278.
  - They estimate fixed-effects logit models, using district fixed effects in the main model (Table 1, col. 1) and incumbent fixed effects as a robustness check (col. 2).
  - Identification comes only from units whose vote switched between 2013 and 2018. Districts or members voting the same way both times drop out.
  - There is no train/test split or cross-validation. This is an in-sample causal and inferential design.

- **Estimating equation:**
  - The dependent variable is 1 if the member voted "aye" on the reform amendment (against sugar interests) and 0 otherwise.
  - The key regressor is inflation-adjusted sugar industry contributions, entered linearly in levels (real dollars, not logged).
  - The headline coefficients are unstandardised log-odds per dollar: −0.0006 with district fixed effects and −0.0004 with incumbent fixed effects, both p < 0.01.

- **Controls in the preferred specification:**
  - Member characteristics: American Conservative Union ideology score (1–100, higher = more conservative) and tenure in terms.
  - District characteristics from the Census: poverty rate, % with a bachelor's degree, median income, and % of the population over 65.
  - A dummy for membership on the House Agriculture Committee.
  - A constant is also reported.

- **Data construction and preprocessing:**
  - Votes come from GovTrack.us.
  - Contributions come from the Center for Responsive Politics. The authors aggregate all sugar industry PAC contributions plus individual contributions over $200 from sugar industry employees or their families, deflated to real terms.
  - Contributions are computed for incumbents in the 113th and 115th Congresses.
  - The main window runs from one year before each vote through the end of that vote's calendar year.
  - The authors checked Leadership PACs and single-candidate Super PACs and found essentially no sugar money there, so these are excluded.
  - Anti-sugar contributions are omitted because they are negligible.

- **Estimation samples:**
  - District fixed effects model: 93 vote-switching districts × 2 votes = 186 observations.
  - Incumbent fixed effects model: restricted to the 53 same-incumbent members who voted both times and switched, giving 106 observations.

- **Inference and fit:**
  - p-values use robust standard errors; no clustering is mentioned.
  - Pseudo R² is 0.745 for the district model and 0.721 for the incumbent model.
  - Marginal effects of contributions, ideology and tenure on P(aye) are plotted with 95% confidence intervals (Figs. 1–3). They are computed with the Stata Marhis package at 50 equally spaced values of each variable, with other covariates at their observed values.

- **Robustness checks:**
  - **Alternative contribution windows (Table 3; full models in Appendix Table A.2):** the coefficients remain negative and significant at the 1% level under both fixed-effects models.
    - Calendar years of the votes only (2013 and 2018).
    - The 12 months up to each vote date (6/20/12–6/20/13 and 5/17/17–5/17/18), which excludes post-vote money.
  - **Ideology measure:** DW-NOMINATE replaces the ACU score.
  - **Party:** a Republican dummy is significant alone but insignificant once an ideology score is included.
  - **Extra controls:** unemployment and % rural do not change the results.
  - **Original aggregation:** contributions summed by election cycle are reported in Appendix Table A.3.

- **Descriptive supplement (Table 2):**
  - Among the 53 same-incumbent switchers, 47 moved from Aye to No, and their contributions rose about 67%.
  - Among the 40 districts with a new incumbent, 32 moved from Aye to No, and their contributions rose about 348%.

recode_vote <- function(v) {
  if (is.character(v) || is.factor(v)) {
    s <- tolower(trimws(as.character(v)))
    y <- ifelse(s %in% c("yes", "yea", "aye", "y", "1"), 1,
                ifelse(s %in% c("no", "nay", "n", "0"), 0, NA))
    return(as.numeric(y))
  }
  y <- suppressWarnings(as.numeric(v))
  vals <- sort(unique(y[!is.na(y)]))
  if (all(vals %in% c(0, 1))) return(y)
  if (all(vals %in% 1:9) && max(vals) > 2) {
    # ICPSR-style coding: 1-3 yea, 4-6 nay, 7-9 not voting
    return(ifelse(y <= 3, 1, ifelse(y <= 6, 0, NA)))
  }
  if (all(vals %in% c(1, 2))) return(ifelse(y == 1, 1, 0))
  ifelse(is.na(y), NA, as.numeric(y == 1))
}

prep <- function(file) {
  d <- as.data.frame(zap_labels(read_dta(file.path(base, file))))
  cat("File:", file, " vars:", paste(names(d), collapse = ", "), "\n")
  vcol <- intersect(c("vote", "Vote", "aye", "yea", "votes"), names(d))[1]
  d$y <- recode_vote(d[[vcol]])
  cat("y table:\n"); print(table(d$y, useNA = "ifany"))
  # incumbent key
  if (!is.null(d$cid) && any(!is.na(d$cid) & as.character(d$cid) != "")) {
    d$ikey <- as.character(d$cid)
  } else if (!is.null(d$name)) {
    d$ikey <- as.character(d$name)
  } else {
    d$ikey <- as.character(d$id)
  }
  d
}

# usable covariates: present and not mostly missing
get_covs <- function(d) {
  cv <- intersect(covs_all, names(d))
  cv <- cv[sapply(cv, function(v) mean(!is.na(suppressWarnings(as.numeric(d[[v]])))) > 0.5)]
  cv
}

switchers <- function(d, key, covs) {
  d <- d[!is.na(d[[key]]) & d[[key]] != "", ]
  d <- d[complete.cases(d[, c("y", covs)]), ]
  if (nrow(d) == 0) return(d)
  v <- tapply(d$y, d[[key]], function(z) length(unique(z)) > 1)
  keep <- names(v)[v]
  d[d[[key]] %in% keep, ]
}

# choose a district key that yields a non-empty switcher sample
choose_dkey <- function(d, covs) {
  cands <- list()
  for (nm in c("id", "stcd", "cd", "district_id", "distid")) {
    if (!is.null(d[[nm]])) cands[[nm]] <- as.character(d[[nm]])
  }
  if (!is.null(d$state) && !is.null(d$district))
    cands[["state_district"]] <- paste(d$state, d$district, sep = "_")
  best <- NULL; bestn <- -1
  for (nm in names(cands)) {
    d$dkey <- cands[[nm]]
    tab <- table(d$dkey)
    if (length(tab) < 50) next
    n <- nrow(switchers(d, "dkey", covs))
    cat("dkey candidate", nm, ": groups", length(tab), " max size", max(tab), " switcher obs", n, "\n")
    # prefer keys that look like districts (<= 2 obs per group per sample)
    score <- n + ifelse(max(tab) <= 2, 1e6, 0) * (n > 0)
    if (score > bestn) { bestn <- score; best <- nm }
  }
  if (is.null(best)) stop("No valid district key found")
  cat("Using dkey:", best, "\n")
  cands[[best]]
}

run_models <- function(file) {
  d <- prep(file)
  covs <- get_covs(d)
  cat("Covariates used:", paste(covs, collapse = ", "), "\n")
  fml_d <- as.formula(paste("y ~", paste(covs, collapse = " + "), "| dkey"))
  fml_i <- as.formula(paste("y ~", paste(covs, collapse = " + "), "| ikey"))
  d$dkey <- choose_dkey(d, covs)
  dd <- switchers(d, "dkey", covs)
  # incumbent sample: same incumbent in both votes
  if (!is.null(d$both)) {
    di <- d[!is.na(d$both) & d$both == 1, ]
    if (nrow(switchers(di, "ikey", covs)) == 0) di <- d
  } else {
    di <- d
  }
  di <- switchers(di, "ikey", covs)
  cat("District switcher obs:", nrow(dd), " Incumbent switcher obs:", nrow(di), "\n")
  md <- feglm(fml_d, data = dd, family = binomial("logit"), vcov = "hetero")
  mi <- feglm(fml_i, data = di, family = binomial("logit"), vcov = "hetero")
  cd <- tryCatch(clogit(as.formula(paste("y ~", paste(covs, collapse = " + "), "+ strata(dkey)")),
                        data = dd, robust = TRUE), error = function(e) NULL)
  ci <- tryCatch(clogit(as.formula(paste("y ~", paste(covs, collapse = " + "), "+ strata(ikey)")),
                        data = di, robust = TRUE), error = function(e) NULL)
  list(md = md, mi = mi, cd = cd, ci = ci, nd = nrow(dd), ni = nrow(di))
}

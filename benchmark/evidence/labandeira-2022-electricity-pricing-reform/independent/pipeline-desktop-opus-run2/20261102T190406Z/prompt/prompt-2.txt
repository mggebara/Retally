The cutoff stops before an April 2014 regulatory price cut. Electricity consumption (kWh) and expenditure (€) come from the last paid bill (previous month) and are annualised by the survey (multiplied by the number of bills per year).

D = 1 if the first interview is before R and the second after R (treated). D = 0 if both interviews are before R (control). T (the key regressor) = 1 for interviews after the reform, i.e. the treated household's second interview. Because bills cover the previous month, the response is expected about one month after the reform.
- **Estimating equation (eq. 4)**: log-log structural demand model ln(q_it) = α + β ln(p_it) + β ln(y_it) [+ ln(y)²] + γX_it + δT_it + θ_i + φ_t + ε_it. It is unstandardised, in log points. The same specification is re-run with ln(electricity expenditure) as the dependent variable. Table 2 also includes "months since reform".

# ---- LIML ----
prune <- function(W) {
  W <- W[, colSums(abs(W)) > 1e-10, drop = FALSE]
  qw <- qr(W, tol = 1e-7)
  W[, qw$pivot[seq_len(qw$rank)], drop = FALSE]
}
liml <- function(y, x, W, Z, cl) {
  W <- prune(W)
  Zf <- cbind(W, Z)
  qZ <- qr(Zf); qW <- qr(W)
  Y <- cbind(y, x)
  S1 <- crossprod(qr.resid(qZ, Y)); S0 <- crossprod(qr.resid(qW, Y))
  k <- min(Re(eigen(solve(S1, S0))$values))
  X <- cbind(lnp = x, W)
  MX <- qr.resid(qZ, X); My <- qr.resid(qZ, y)
  A <- crossprod(X) - k * crossprod(MX)
  bv <- crossprod(X, y) - k * crossprod(MX, My)
  b <- drop(solve(A, bv))
  names(b) <- colnames(X)
  u <- drop(y - X %*% b)
  Xt <- X - k * MX
  sc <- rowsum(Xt * u, cl)
  Ai <- solve(A)
  V <- Ai %*% crossprod(sc) %*% Ai
  se <- sqrt(diag(V)); names(se) <- colnames(X)
  # first stage F (non-robust) for diagnostics
  list(b = b, se = se, kappa = k)
}

Methodology: - **Data and sample:** Spanish Household Budget Survey (HBS, INE) microdata. The sample is limited to households interviewed between August 2011 and April 2014, so that no other major events (such as the April 2014 price change) fall inside the window. This gives a rotating two-year household panel of 25,775 observations. Each household is interviewed twice, in the same two-week period of consecutive years. Sampling is stratified into 26 two-week subsamples per year. Electricity consumption (kWh) and expenditure (€) come from the last paid bill (the month before the interview), scaled up to annual by the number of bills per year. The household price is p = expenditure/consumption in €/kWh, including all taxes. The estimation sample in Table 2 has 20,872 observations from 10,729 households.

Households are grouped by interview dates. In the control group (D=0) both interviews fell before the reform. In the treated group (D=1) the first interview was before the reform and the second after it. The treatment variable is T = 1 for post-reform interviews (only treated households' second interview), and its coefficient δ is the DiD estimator. The paper treats the interview date as exogenous, because the survey design makes the subsamples balanced on observables. Balance is checked with Table 1 and pre-reform QQ-plots of covariates (Fig. 4).

liml <- function(data, yv, endog, exog, excl) {
  exog <- exog[exog %in% names(data)]
  excl <- excl[excl %in% names(data)]
  cc <- complete.cases(data[, c(yv, endog, exog, excl)])
  dd <- data[cc, ]
  y <- dd[[yv]]
  X1 <- as.matrix(dd[, exog, drop = FALSE])
  q1 <- qr(X1)
  X1 <- X1[, q1$pivot[seq_len(q1$rank)], drop = FALSE]
  Ye <- as.matrix(dd[, endog, drop = FALSE])
  Z <- cbind(X1, as.matrix(dd[, excl, drop = FALSE]))
  qZ <- qr(Z); qX <- qr(X1)
  W <- cbind(y, Ye)
  MZW <- qr.resid(qZ, W)
  MXW <- qr.resid(qX, W)
  A <- crossprod(MZW); B <- crossprod(MXW)
  kap <- min(Re(eigen(solve(A, B))$values))
  X <- cbind(Ye, X1)
  MZX <- cbind(MZW[, -1, drop = FALSE], matrix(0, nrow(X1), ncol(X1)))
  XtX <- crossprod(X) - kap * crossprod(MZX)
  Xty <- crossprod(X, y) - kap * crossprod(MZX, MZW[, 1])
  b <- solve(XtX, Xty)
  b <- setNames(as.numeric(b), colnames(X))
  list(coef = b, n = nrow(dd), kappa = kap)
}

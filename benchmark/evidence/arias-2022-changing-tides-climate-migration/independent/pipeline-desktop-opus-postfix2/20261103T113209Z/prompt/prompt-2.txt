Methodology: - **Design / data (Study 1):** Choice-based (forced-choice, paired-profile) conjoint experiment fielded by Dynata on nationally representative online samples: 1,086 U.S. and 1,074 German respondents (2,160 total), each shown 9 pairs of randomized migrant profiles, giving 18,966 (U.S.) and 18,862 (Germany) profile-level observations ("unique choice tasks"). A pre-treatment battery measured age, gender, education, religiosity, trust in government, political interest, ideology, partisanship, foreign-policy orientation and empathy (used for subgroup analyses, not as controls in the main AMCE models).
- **Attributes and baselines (Table 1; baseline listed first):** Reason for migration (Economic opportunity [baseline], Drought, Flooding, Wildfires, Political/Religious/Ethnic persecution — focal attribute); Language fluency (None, Broken, Fluent); Gender (Female, Male); Occupation (Unemployed, Cleaner, Teacher, Doctor); Religion (Atheist/Agnostic, Christian, Muslim); Origin (Another region in your country, Afghanistan, Ethiopia, Myanmar, Ukraine); Vulnerability (None, PTSD, Food insecurity, No surviving family members, Physically handicapped). - **Estimand / estimating equation:** Average Marginal Component Effect (AMCE; Hainmueller, Hopkins & Yamamoto 2014), estimated as a linear probability model (OLS) of a binary outcome — whether the profile was chosen/preferred for settlement in the respondent's state (1 = chosen, 0 = not) — on dummy indicators for all non-baseline levels of all seven attributes (no interactions in the main model, no respondent covariates or fixed effects). Coefficients are unstandardised changes in the probability (percentage points/100) that a profile is preferred relative to the baseline level.
- **Samples / estimation:** Models estimated separately for the U.S. and German samples. Main ("full") model uses all profiles (Figure 1 left panel; Table 2). Subset models: internal-migrant profile pairs only (origin = "another region in your country") and international-migrant profile pairs only (Figure 1 middle/right panels). No train/test split or cross-validation (experimental inference).
- **Standard errors / inference:** Robust standard errors clustered by respondent; Table 2 stars at *** p<0.01, ** p<0.05, * p<0.1; Figure 1 shows 90% confidence intervals.

sgrepl <- function(p, x) {
  x <- as.character(x)
  tryCatch(grepl(p, x, ignore.case = TRUE, perl = TRUE),
           error = function(e) grepl(p, x, ignore.case = TRUE, useBytes = TRUE))
}
clean_txt <- function(x) {
  x <- as.character(x)
  x <- tryCatch(gsub('<[^>]+>', '', x, perl = TRUE), error = function(e) gsub('<[^>]+>', '', x, useBytes = TRUE))
  trimws(x)
}

code_choice <- function(x) {
  x <- trimws(as.character(x))
  out <- rep(NA_integer_, length(x))
  hd <- grepl('[0-9]', x)
  out[hd] <- suppressWarnings(as.integer(sub('^.*?([0-9]+)[^0-9]*$', '\\1', x[hd], perl = TRUE)))
  nd <- !hd & !is.na(x) & x != ''
  out[nd & grepl('A\\s*$', x)] <- 1L
  out[nd & grepl('B\\s*$', x)] <- 2L
  out
}

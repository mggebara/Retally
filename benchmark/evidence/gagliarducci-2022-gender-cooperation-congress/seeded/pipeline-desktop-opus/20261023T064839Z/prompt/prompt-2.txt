Title: NBER WORKING PAPER SERIES
Methodology: - **Data and unit of analysis**: All House public bills from the 101st Congress (elected 1988) to the 111th (elected 2008), taken from THOMAS and cross-checked against the Congressional Bills Project and Fowler's cosponsorship data. These are linked to member biographies (ICPSR up to the 104th Congress, then the Bioguide), Clerk of the House election returns, and Census district demographics. The analysis is run at the bill level (bill j, sponsor i, district k, Congress t). Simple, concurrent and joint resolutions and private bills are excluded. Results are shown pooled and separately for Democrats and Republicans.
- **Dependent variables, in levels with no logs**: (a) the total number of cosponsors on a bill, a measure of coalition-building; (b) the percent of cosponsors from the opposite party, divided by (number of cosponsors + 1) so the sponsor is counted and bills with zero cosponsors are kept, a measure of bipartisanship. Robustness checks divide by cosponsors only, or use the count of opposite-party cosponsors with the number of cosponsors as a control. Nothing in the text says the coefficients are standardized: the Female coefficient is a raw difference in cosponsor counts and in percentage points.
- **Main OLS specification (eq. 4, Table 3)**: Y_ijkt = α + β·Female_i + c_t + Bill_j + Spons_it + Distr_kt + ε. The key regressor is a dummy for a female sponsor. Controls are added step by step across columns:
  - (1) Congress (time) fixed effects only.
  - (2) adds bill-category dummies: 226 minor topics (Adler–Wilkerson classification) and 33 committees of referral.
  - (3) adds individual controls: tenure, a rookie dummy, age, a committee chair/ranking member dummy, Ivy League attendance, 5 previous-occupation dummies, and total bills sponsored.
  - (4) adds district controls instead of individual ones: 3 macro-region dummies, % black, % urban, % foreign-born, % over 65, log median income, log population density.
  - (5) the preferred specification, with all bill, individual and district controls.
  - Specifications with district fixed effects were tried but were too imprecise to be informative.
- **Supporting regressions (Table 1)**: A linear model of whether a bill passes the House on the number of cosponsors, the % of opposite-party cosponsors and their interaction (col. 1). Col. 2 adds interactions of each term with the female dummy, and a joint F-test that the three interactions are zero gives p = 0.12. With district and sponsor controls, 10 more cosponsors go with a +0.67 percentage-point probability of passing the House and +0.19 percentage points of becoming law. Separately, the predicted Republican vote share comes from an OLS regression on the district controls listed above (Figure 1). DW-NOMINATE first-dimension scores and Party Unity Scores are compared by gender within each party (Figures 2–3).
- **Addressing selection with a regression discontinuity (eq. 5)**: Y = α + β·Female + γ·Female·f(MV) + f(MV) + c_t + ε. The running variable MV is the female candidate's margin of victory against a male candidate in mixed-gender races, and f(·) is allowed to differ on each side of the zero threshold, with Congress fixed effects. The sample is restricted to districts with a mixed-gender race. McCrary density tests show no discontinuity in the pooled sample, but a clear discontinuity among Republicans (male candidates win more close races), which weakens the design when it is run by party. Matching on district and individual characteristics is used as another estimator. The details of bandwidth, polynomial order and the matching algorithm are in a part of the paper that is missing from the text provided.
- **Inference and evaluation**: There is no train/test split or cross-validation, since this is causal and descriptive econometrics. The evidence is the coefficient on Female, its significance at conventional levels, and how stable it is across columns and estimators (OLS, RD, matching), by party. The provided text does not say how standard errors are computed. Clustering at the sponsor or Congress-member level would be the natural choice, but that is not confirmed here.
- **Heterogeneity checks (described in the introduction)**: The gender gap is also estimated for the female share of cosponsors, for the seniority, status and influence of the cosponsors recruited, by sponsor seniority, and for bills on women's issues compared with other bills.

fit_ols <- function(depvar, sub, xvars, fe, wvar = NULL) {
  vars <- unique(c(depvar, "sponsor_female", xvars, fe, "group_sponsor", wvar))
  dd <- sub[complete.cases(sub[, ..vars])]
  rhs <- paste(bt(c("sponsor_female", xvars)), collapse = " + ")

  if (is.null(wvar)) {
    m <- feols(fml, data = dd, cluster = ~group_sponsor, fixef.rm = "none", notes = FALSE, warn = FALSE)
  } else {
    dd[, .wt := get(wvar)]

  se <- unname(sqrt(diag(vcov(m)))["sponsor_female"])

}

# Stata-like probit: drops regressors where x!=0 predicts outcome perfectly (and those obs),
# collinear regressors get coefficient 0, and predict (default 'rules') is missing for obs excluded by rules.
stata_probit_predict <- function(est, pred, xvars) {
  vars <- c("sponsor_female", "v2", xvars)
  e <- as.data.frame(est[complete.cases(est[, ..vars]), ..vars])
  levs <- sort(unique(e$v2))
  baselev <- levs[1]
  dumnames <- paste0("v2_", levs[-1])
  X <- as.data.frame(lapply(levs[-1], function(l) as.numeric(e$v2 == l)))
  if (length(dumnames) > 0) names(X) <- dumnames
  X <- cbind(X, e[, xvars, drop = FALSE])
  y <- e$sponsor_female
  keep_rows <- rep(TRUE, nrow(e))
  dropped_vars <- character(0)
  repeat {
    changed <- FALSE
    for (v in setdiff(names(X), dropped_vars)) {
      nz <- keep_rows & X[[v]] != 0
      if (sum(nz) > 0) {
        yy <- y[nz]
        if (all(yy == 0) || all(yy == 1)) {
          dropped_vars <- c(dropped_vars, v)
          keep_rows <- keep_rows & !(X[[v]] != 0)
          changed <- TRUE
        }
      }
    }
    if (!changed) break
  }
  usevars <- setdiff(names(X), dropped_vars)
  Xm <- as.matrix(cbind(`(Intercept)` = 1, X[keep_rows, usevars, drop = FALSE]))
  fit <- suppressWarnings(glm.fit(Xm, y[keep_rows], family = binomial(link = "probit"),
                                   control = glm.control(maxit = 200, epsilon = 1e-10)))
  cf <- fit$coefficients
  cf[is.na(cf)] <- 0
  names(cf) <- colnames(Xm)
  # prediction
  P <- as.data.frame(pred)
  xb <- rep(cf["(Intercept)"], nrow(P))
  for (v in usevars) {
    if (startsWith(v, "v2_")) {
      l <- as.numeric(sub("^v2_", "", v))
      xb <- xb + cf[v] * as.numeric(P$v2 == l)
    } else {
      xb <- xb + cf[v] * P[[v]]
    }
  }
  ps <- pnorm(xb)
  ps[is.na(P$v2)] <- NA
  for (v in xvars) ps[is.na(P[[v]])] <- NA
  for (v in dropped_vars) {
    if (startsWith(v, "v2_")) {
      l <- as.numeric(sub("^v2_", "", v))
      ps[!is.na(P$v2) & P$v2 == l] <- NA
    } else {
      ps[!is.na(P[[v]]) & P[[v]] != 0] <- NA
    }
  }
  as.numeric(ps)
}

get_band <- function(y, x) {
  ok <- !is.na(y) & !is.na(x)
  y <- y[ok]; x <- x[ok]
  h <- NA_real_
  f <- tryCatch(get("rdbwselect_2014", envir = asNamespace("rdrobust")), error = function(e) NULL)
  extract_h <- function(r) {
    bw <- r$bws
    if (is.matrix(bw) || is.data.frame(bw)) return(as.numeric(as.matrix(bw)[1, 1]))
    as.numeric(unlist(bw))[1]
  }
  if (!is.null(f)) {
    for (kn in c("uniform", "uni")) {
      if (!is.na(h)) break
      h <- tryCatch(extract_h(f(y = y, x = x, c = 0, kernel = kn, bwselect = "CCT")),
                    error = function(e) NA_real_)
    }
  }
  if (is.na(h)) {
    h <- tryCatch(as.numeric(rdbwselect(y = y, x = x, c = 0, kernel = "uniform", bwselect = "mserd")$bws[1, 1]),
                  error = function(e) NA_real_)
  }
  h
}

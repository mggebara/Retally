Title: NBER WORKING PAPER SERIES
Methodology: - **Data and unit of analysis**: The unit is the bill. The sample covers all House public bills (simple, concurrent and joint resolutions and private bills are excluded) from the 101st Congress (elected 1988) to the 111th (elected 2008). Bills come from THOMAS and are cross-checked against Adler–Wilkerson's Congressional Bills Project and Fowler's cosponsorship data, which also supply the topic and passage outcomes. The bills are linked to sponsor biographies (ICPSR up to the 104th Congress, then the Biographical Directory), to House Clerk election returns and to Census district characteristics.
- **Outcome variables**: There are two cooperation measures. (a) Coalition building: the total number of cosponsors on a bill, in levels; the paper does not say it is logged or standardised. (b) Bipartisanship: the percent of cosponsors from the opposite party, out of the number of cosponsors plus 1 (the sponsor), so that bills with zero cosponsors are kept. The paper says results are robust to dividing by the number of cosponsors alone, or to using the count of opposite-party cosponsors with the number of cosponsors as a control.
- **Baseline OLS specification (eq. 4, Table 3)**: Y_ijkt = α + β·Female_i + c_t + Bill_j + Spons_it + Distr_kt + ε_ijkt. It is estimated for the pooled sample and separately for Democrats and Republicans. The columns build up step by step: (1) Congress (time) fixed effects only; (2) adds bill-category dummies, i.e. 226 minor-topic dummies (Adler–Wilkerson classification) and dummies for the 33 committees of referral; (3) adds sponsor controls instead: tenure, a rookie dummy, age, a committee chair or ranking member dummy, an Ivy League dummy, 5 previous-occupation dummies and the total number of bills sponsored; (4) adds district controls only: 3 macro-region dummies, % black, % urban, % foreign-born, % over 65, log median income and log population density; (5) the preferred specification, with all bill, individual and district controls. Coefficients are unstandardised: a difference in the number of cosponsors, or in percentage points of opposite-party cosponsors.
- **Supporting regressions**: Table 1 regresses the probability that a bill passes the House on the number of cosponsors, the % of opposite-party cosponsors and their interaction. Column 2 adds interactions with a female dummy; the joint test that all three interactions are zero gives p = 0.12. Figure 1's predicted Republican vote share comes from an OLS regression of the actual Republican vote share on the district controls. Specifications with district fixed effects were tried but gave imprecise estimates because gender varies little within districts. The paper also reports that 10 more cosponsors raise the probability of passing the House by 0.67 percentage points and of becoming law by 0.19 percentage points.
- **Regression discontinuity (eq. 5)**: The RD sample is limited to representatives elected in mixed-gender (male vs female) races. The specification is Y = α + β·Female + Female×f(MV) + f(MV) + c_t + ε, where MV is the female candidate's margin of victory over the male candidate, with separate polynomials on each side of the cutoff at 0. It is run pooled and by party. A McCrary density test does not reject continuity in the pooled sample, but there is a strong discontinuity for Republicans, with male winners much more common, so the authors caution that the party-specific RD rests on stronger assumptions.
- **Matching**: Matching is also used as a robustness approach to selection of women into districts. Its details (bandwidth or polynomial order for the RD, the matching covariates, the inference method) are not in the text provided.
- **Inference and standard errors**: The text provided does not say how standard errors are computed (robust or clustered, and on what). Significance is reported at conventional levels. Since there are many bills per sponsor, clustering by Congress member is likely but is not stated.
- **Additional analyses** (described in the introduction): gender of the cosponsors (women attract more female cosponsors); seniority, status and influence of the cosponsors; heterogeneity by sponsor seniority; and heterogeneity by bill topic (women's-issues bills).

run_reg <- function(sub, y, rhs, fe, wvar = NULL) {
  sub <- sub[!is.na(sub$group_sponsor) & !is.na(sub[[y]]), , drop = FALSE]
  if (!is.null(wvar)) sub <- sub[!is.na(sub[[wvar]]) & is.finite(sub[[wvar]]), , drop = FALSE]
  fml <- as.formula(paste(y, "~", paste(rhs, collapse = " + "), "|", paste(fe, collapse = " + ")))
  if (is.null(wvar)) {
    m <- feols(fml, data = sub, cluster = ~group_sponsor, fixef.rm = "none", warn = FALSE, notes = FALSE)
  } else {
    sub$.w <- sub[[wvar]]
    m <- feols(fml, data = sub, weights = ~.w, cluster = ~group_sponsor, fixef.rm = "none", warn = FALSE, notes = FALSE)
  }
  used <- tryCatch(fixest::obs(m), error = function(e) seq_len(nobs(m)))
  list(b = unname(coef(m)["sponsor_female"]),
       se = unname(sqrt(diag(vcov(m)))["sponsor_female"]),
       n = nobs(m),
       nclust = length(unique(sub$group_sponsor[used])))
}

# Probit emulating Stata: i.v2 with lowest level as base; non-base levels that
# perfectly predict the outcome are omitted (obs dropped, coefficient = 0).
probit_pscore <- function(fitdat, preddat, xvars) {
  vars <- c("sponsor_female", "v2", xvars)
  f <- fitdat[complete.cases(fitdat[, vars, drop = FALSE]), , drop = FALSE]
  lev <- sort(unique(f$v2))
  base <- lev[1]
  nb <- lev[-1]
  bad <- nb[sapply(nb, function(l) length(unique(f$sponsor_female[f$v2 == l])) < 2)]
  if (length(bad) > 0) f <- f[!(f$v2 %in% bad), , drop = FALSE]
  keep_lev <- setdiff(nb, bad)
  mk <- function(dd) {
    X <- matrix(1, nrow(dd), 1, dimnames = list(NULL, "(Intercept)"))
    for (l in keep_lev) {
      X <- cbind(X, as.numeric(dd$v2 == l))
      colnames(X)[ncol(X)] <- paste0("v2_", l)
    }
    for (v in xvars) {
      X <- cbind(X, as.numeric(dd[[v]]))
      colnames(X)[ncol(X)] <- v
    }
    X
  }
  Xf <- mk(f)
  g <- suppressWarnings(glm.fit(Xf, f$sponsor_female, family = binomial(link = "probit")))
  beta <- g$coefficients
  beta[is.na(beta)] <- 0
  Xp <- mk(preddat)
  as.vector(pnorm(Xp %*% beta))
}

get_bw <- function(y, x) {
  h <- NA_real_
  if (exists("rdbwselect_2014", envir = asNamespace("rdrobust"), inherits = FALSE)) {
    r <- tryCatch(rdrobust::rdbwselect_2014(y = y, x = x, c = 0, kernel = "uniform", bwselect = "CCT"),
                  error = function(e) NULL)
    if (!is.null(r)) h <- tryCatch(as.numeric(r$bws[1, 1]), error = function(e) NA_real_)
  }
  if (is.na(h)) {
    r <- tryCatch(rdrobust::rdbwselect(y = y, x = x, c = 0, kernel = "uniform", p = 1, bwselect = "mserd"),
                  error = function(e) NULL)
    if (!is.null(r)) h <- tryCatch(as.numeric(r$bws[1, 1]), error = function(e) NA_real_)
  }
  h
}

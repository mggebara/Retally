Methodology: # Experimental Methodology Summary

- **Identification strategy**: Sharp/fuzzy regression discontinuity (RD) design exploiting the 500 hectare cumulative-landholdings threshold from El Salvador's 1980 Decree 153 land reform, which determined whether a property was expropriated and converted into a cooperative.

- **Estimating equation**: `y_po = α + γ·Above500_o + f(holdings_o) + ε_po`, where the dependent variable `y_po` varies by outcome (e.g., share of land in cash vs. staple crops, crop yields, interquartile range of worker earnings), the key regressor `Above500_o` is an indicator for the former owner having ≥500 ha cumulative landholdings, and `f(holdings_o)` is a smooth RD polynomial in the running variable (owner's total prereform landholdings). - **Preferred specification details**: Local linear polynomial estimated separately on each side of the cutoff; MSE-optimal bandwidth from Calonico, Cattaneo, Titiunik (2014b) and Calonico et al. - **Standard errors**: Clustered at the former-landholder level (since owners could own multiple plots and the running variable is defined at owner level).

- **Sample / observations**: Plot-level data from El Salvador's 2007 IV Census of Agriculture (94,168 producers), matched to prereform 1980 Property Registry records via name, municipality, department, and size (~70% match rate, with no discontinuity in match probability at threshold). - **Identification tests**: (i) McCrary (2008) density/sorting test around 500 ha threshold; (ii) RD balance tests on geographic covariates (land suitability, precipitation, elevation, suitability for sugarcane/coffee/cotton/maize/beans/rice/sorghum); (iii) check for discontinuity in match probability.

safe_coef <- function(m, name) {
  if (is.null(m)) return(NA_real_)
  cfs <- coef(m)
  if (name %in% names(cfs)) cfs[name] else NA_real_
}

run_level <- function(bw) {
  d <- df_est %>% filter(abs(dist) <= bw)
  d$dist_above <- d$Above500 * d$dist
  nclust <- length(unique(d$cluster_id[!is.na(d$cluster_id)]))
  cat(sprintf("  level bw=%g: n=%d, clusters=%d\n", bw, nrow(d), nclust))
  m <- tryCatch(
    feols(y_level ~ Above500 + dist + dist_above,
          data = d, cluster = ~cluster_id),
    error = function(e) { cat("err:", conditionMessage(e), "\n"); NULL }
  )
  list(coef = safe_coef(m, "Above500"),
       n = if (is.null(m)) nrow(d) else nobs(m),
       nclust = nclust)
}

# IQR analysis - compute IQR of worker earnings per property (match_id)
run_iqr <- function(bw) {
  d <- df_est %>% filter(abs(dist) <= bw, !is.na(cluster_id))
  prop_data <- d %>%
    group_by(cluster_id) %>%
    summarise(iqr = IQR(y_level, na.rm = TRUE),
              Above500 = first(Above500),
              dist = first(dist),
              n_workers = n(),
              .groups = "drop") %>%
    filter(!is.na(iqr))
  prop_data$dist_above <- prop_data$Above500 * prop_data$dist
  cat(sprintf("  iqr bw=%g: nprops=%d\n", bw, nrow(prop_data)))
  m <- tryCatch(
    feols(iqr ~ Above500 + dist + dist_above, data = prop_data, se = "hetero"),
    error = function(e) NULL
  )
  list(coef = safe_coef(m, "Above500"),
       n = if (is.null(m)) nrow(prop_data) else nobs(m),
       nclust = nrow(prop_data))
}

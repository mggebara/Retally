- **Identification strategy**: Sharp/fuzzy regression discontinuity (RD) design exploiting the 500 hectare cumulative-landholdings threshold from El Salvador's 1980 Decree 153 land reform, which determined whether a property was expropriated and converted into a cooperative.

- **Estimating equation**: `y_po = α + γ·Above500_o + f(holdings_o) + ε_po`, where the dependent variable `y_po` varies by outcome (e.g., share of land in cash vs. staple crops, crop yields, interquartile range of worker earnings), the key regressor `Above500_o` is an indicator for the former owner having ≥500 ha cumulative landholdings, and `f(holdings_o)` is a smooth RD polynomial in the running variable (owner's total prereform landholdings). - **Preferred specification details**: Local linear polynomial estimated separately on each side of the cutoff; MSE-optimal bandwidth from Calonico, Cattaneo, Titiunik (2014b) and Calonico et al. (2017); uniform kernel. Fuzzy RD estimates also reported, instrumenting cooperative status with the Above500 rule. First stage: crossing the threshold raises expropriation probability by ~75%.

- **Standard errors**: Clustered at the former-landholder level (since owners could own multiple plots and the running variable is defined at owner level).

- **Sample / observations**: Plot-level data from El Salvador's 2007 IV Census of Agriculture (94,168 producers), matched to prereform 1980 Property Registry records via name, municipality, department, and size (~70% match rate, with no discontinuity in match probability at threshold). Sample restricted to the "risk set" of former owners within the MSE-optimal bandwidth around 500 ha. Worker income analysis uses 2002–2013 Encuesta de Hogares de Propósitos Multiples, restricted to cantons with only one cooperative/large hacienda to enable matching (verified 91% accuracy using 2008–2010 name data).

- **Identification tests**: (i) McCrary (2008) density/sorting test around 500 ha threshold; (ii) RD balance tests on geographic covariates (land suitability, precipitation, elevation, suitability for sugarcane/coffee/cotton/maize/beans/rice/sorghum); (iii) check for discontinuity in match probability.

- **Robustness** (Appendix J/D): Alternative RD polynomial orders, alternative bandwidths, matching methods, and sensitivity analysis assuming reform properties sit at the edge of balance-test confidence intervals.

- **Outcomes/evaluation**: Four model-derived predictions tested — (1) share of land in cash vs. staple crops, (2) cash crop yields, (3) staple crop yields, (4) interquartile range of worker earnings — with results plotted as RD graphs (25-ha bins) and reported as point estimates with clustered SEs.

safe_coef <- function(m, name) {
  if (is.null(m)) return(NA_real_)
  cfs <- coef(m)
  if (name %in% names(cfs)) cfs[name] else NA_real_
}

run_level <- function(bw) {
  d <- df_est %>% filter(abs(dist) <= bw)
  d <- d %>% filter(!is.na(.data[[cluster_var]]))
  d$dist_above <- d$Above500 * d$dist
  m <- tryCatch(
    feols(Work_Income ~ Above500 + dist + dist_above | survey_year,
          data = d, cluster = as.formula(paste0("~", cluster_var))),
    error = function(e) NULL
  )
  if (is.null(m)) {
    m <- tryCatch(
      feols(Work_Income ~ Above500 + dist + dist_above | survey_year,
            data = d, se = "hetero"),
      error = function(e) NULL
    )
  }
  if (is.null(m)) {
    m <- tryCatch(feols(Work_Income ~ Above500 + dist + dist_above, data = d, se = "hetero"),
                  error = function(e) NULL)
  }
  list(coef = safe_coef(m, "Above500"),
       n = if (is.null(m)) NA_integer_ else nobs(m),
       nclust = length(unique(d[[cluster_var]][!is.na(d[[cluster_var]])])) )
}

build_iqr <- function(bw) {
  d <- df_est %>% filter(abs(dist) <= bw, !is.na(property_id), property_id != "")
  prop_counts <- d %>% group_by(property_id) %>% summarise(n_workers = n())
  valid_props <- prop_counts$property_id[prop_counts$n_workers >= 5]
  d2 <- d %>% filter(property_id %in% valid_props)
  if (nrow(d2) == 0) return(d2[0, ])
  prop_data <- d2 %>%
    group_by(property_id) %>%
    summarise(iqr = IQR(Work_Income, na.rm = TRUE),
              Above500 = first(Above500),
              dist = first(dist),
              owner = first(.data[[cluster_var]]),
              survey_year = first(survey_year),
              .groups = "drop")
  prop_data
}

    return(list(coef = NA_real_, n = 0L, nclust = 0L))

    return(list(coef = NA_real_, n = 0L, nclust = 0L))

  has_owner <- any(!is.na(pd$owner))
  pd_cl <- if (has_owner) pd %>% filter(!is.na(owner)) else pd
  m <- NULL

    )

  if (is.null(m)) {

  }
  if (is.null(m)) {
    m <- tryCatch(feols(iqr ~ Above500 + dist, data = pd, se = "hetero"),

  }
  if (is.null(m)) {
    m <- tryCatch(feols(iqr ~ Above500, data = pd, se = "hetero"),
                  error = function(e) NULL)
  }
  list(coef = safe_coef(m, "Above500"),
       n = if (is.null(m)) nrow(pd) else nobs(m),
       nclust = length(unique(pd$owner[!is.na(pd$owner)])) )

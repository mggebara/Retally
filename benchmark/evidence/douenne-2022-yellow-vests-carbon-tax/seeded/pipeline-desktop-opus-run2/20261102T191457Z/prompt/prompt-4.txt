Inattentive and fastest respondents excluded; observations weighted to population frequencies. The survey embeds independent randomized treatments: environmental information (climate change / particulate matter / both / none); sector assignment (housing vs transport) for a sectoral tax and dividend; a "scientists agree the carbon tax is effective" message (half the sample); customized win/lose feedback (2/3 of the sample) and/or progressivity information (1/2), split as feedback only 1/2, progressivity only 1/3, both 1/6; and a targeted-dividend variant with eligibility thresholds at the 20th/30th/40th/50th income percentiles (€780/€1,140/€1,430/€1,670 per month; payments €550/€360/€270/€220 per year). Respondents whose income lies between two thresholds are randomly assigned to one of them.
- **Policy and outcomes**: The main reform is a +€50/tCO2 carbon tax with a €110/year lump-sum dividend per adult (at most 2 adults per household). Outcomes are "approval" (= answers "Yes") and "acceptance" (= does not answer "No"), coded as binary, along with binary beliefs: win/lose category, effectiveness, progressivity. Subjective net gains are elicited in brackets scaled per Eurostat consumption unit (c.u.) and turned into numbers using within-bin averages from Insee data. Belief questions are not incentivized.
- **Objective net gain simulation**: γ_h = N_h^a·D − ΔE_h^transport − ΔE_h^housing (eq. 1), using official Insee surveys: BdF 2011 matched with ENTD 2008 (Douenne 2020, >10,000 households) and EL 2013, all inflated with National Accounts. Price elasticities are −0.4 (transport) and −0.2 (housing), with 80% of the incidence on consumers. ΔE_transport comes from each respondent's reported distance and fuel economy. ΔE_housing is predicted by regressing housing-survey energy-bill increases on household characteristics and applying the coefficients to respondents.
- **Out-of-sample validation of the feedback**: The predictor is trained on the housing survey and tested on the consumer survey (BdF), so it is never tested on its own training data. The win/lose cutoff is made symmetric, giving 83.4% correct for both predicted winners and predicted losers ("five cases out of six"). The prediction is 99% accurate for |gain| > €110/c.u.
- **Bias heterogeneity (Table 2)**: The dependent variable is the dummy "large bias" = |γ̂ − g| > €110/year per c.u. (true for 55% of respondents). It is regressed on Yellow Vests attitude (omitted: opposes), environmentalist, left-right leaning (omitted: extreme left) and sociodemographic and political controls. Estimated by OLS (col. 1, R² = 0.061), logit reporting average marginal effects (col. 2), and OLS adding the initial attitude to the tax (col. 3, R² = 0.098), with N = 3,002 in each. Multiple testing uses Benjamini–Hochberg FDR control at 5%, applied to F-tests of joint nullity for each categorical variable and for the household-composition and income triplets. Standard errors are in parentheses.
- **Belief updating**: Shares of respondents whose post-feedback win/lose belief matches the feedback (Table 3), split by initial belief, with 95% binomial confidence intervals, on the 1,968 respondents who got feedback. Because the feedback is deterministic in the estimated gain γ̂, its causal effect on beliefs is estimated with an RDD at γ̂ = 0, where the feedback dummy Γ̂ jumps from 0 to 1. The same analysis is run on the subsample with |gain| > €110 (Table D.4).
- **Causal effect of beliefs on support (Section IV)**: IV/2SLS-type estimation of binary beliefs on approval/acceptance, using the random treatments as instruments: the feedback near the threshold for self-interest, and the effectiveness message for perceived effectiveness. For self-interest, a fuzzy RDD also uses the randomized eligibility thresholds of the targeted dividend, which shift beliefs about winning around the thresholds. Headline results: not believing one loses raises acceptance by more than 50 p.p., and believing the tax is effective raises approval by more than 40 p.p. Evidence on progressivity is non-causal. clean_col <- function(x) {
  tryCatch({
    cl <- oldClass(x)
    lv <- attr(x, "levels", exact = TRUE)
    vl <- attr(x, "value.labels", exact = TRUE)
    if (!is.null(cl) && ("factor" %in% cl) && !is.null(lv)) {
      codes <- strip_plain(x)
      levs <- strip_plain(lv)
      return(factor(levs[codes], levels = unique(levs)))
    }
    y <- strip_plain(x)
    if (!is.null(vl) && (is.numeric(y))) {
      vals <- strip_plain(attr(vl, "values", exact = TRUE))
      labs <- strip_plain(vl)
      if (length(vals) == length(labs) && length(vals) > 0) {
        nn <- y[!is.na(y)]
        if (length(nn) > 0 && all(nn %in% vals)) {
          y <- labs[match(y, vals)]
        }
      }
    }
    if (!(typeof(y) %in% c("logical", "integer", "double", "character", "complex"))) return(NULL)
    y
  }, error = function(e) NULL)
}

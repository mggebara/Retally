Title: EVALUATING DELIBERATIVE COMPETENCE:
Methodology: - **Design / data**: Two randomized online experiments on Amazon Mechanical Turk (US residents, 18+). Experiment A (Apr–May 2014, 8 sessions, 504 subjects) has 4 between-subject arms: Control (index-fund video), Treatment (compound-interest video based on Malkiel & Ellis 2013, including the rule of 72), Substance-Only and Rhetoric-Only. Experiment B (Oct 2018, 2 sessions, 401 subjects; required ≥500 completed HITs and ≥98% approval) has 2 arms: Control (portfolio diversification) and Treatment (the compound-interest video split into 3 parts, plus 6 practice problems with individualized feedback). Each subject was in exactly one arm. Each experiment has 3 stages: education intervention → 10 pairs of valuation tasks → incentivized 10-question test (5 on compound interest, 5 on the control module). The two experiments are analyzed separately because their samples differ; they are not compared directly.
- **Valuation measurement**: Iterated multiple price lists (Andersen et al. 2006) with a $0.20 resolution give the immediate dollar equivalent of a reward R ∈ {$20, $18, $16, $14, $12} paid in t ∈ {36, 72} days (Table 2). Each reward is shown twice: in a simple frame ("We will pay you $R in t days") and in a complex frame (invest $a at X% daily interest, compounded daily). Task order is randomized at the subject level. Payment: with 75% probability one randomly chosen decision is paid, with 25% probability the test score is paid ($1 per correct answer). Everyone also gets a $10 completion fee.
- **Preprocessing**: Valuations are interval-coded, and the midpoint of the interval is used. Each valuation is normalized as r^f_{i,R,t} = r̃^f_{i,R,t}/R and expressed in percentage points (0–100, i.e. cents per future $1). This is a rescaling, not a standardization; coefficients are in percentage points of the future reward, and test scores are numbers of correct answers out of 5.
- **Sample restrictions**: Subjects who switched two or more times in any price list are dropped (49 of 504 in A, 53 of 401 in B), following Harrison et al. (2005). This leaves 803 subjects who respected monotonicity: 455 in Experiment A across all 4 arms, of which 215 are in Control+Treatment, and 348 in Experiment B. Attrition is reported (4 subjects in A; in B, 2 in Control and 9 in Treatment, a difference significant at 5%) but not adjusted for. Balance was checked with 68 F-tests on demographics (2 significant at 5%, 5 at 10%).
- **Conventional-metric regressions (OLS on treatment indicators, levels parameterization with no constant)**:

  - Table 5: normalized complex-frame valuation r^c on treatment dummies, using all 10 tasks per subject (2,150 obs in A, 3,480 in B), with SEs clustered by subject. Columns 3–6 split by 72- and 36-day delay (1,075 / 1,740 obs). Headline Treatment–Control differences are 14.312 (3.431) for A and 15.134 (2.834) for B.
  - Table 6 (Experiment A, all 4 arms, 455 subjects): the dependent variables are the compound-interest score, the control-module score, the complex-frame valuation and the simple-frame valuation (4,550 obs), each regressed on the 4 arm dummies with SEs clustered by subject. It reports p-values for each arm's difference from Control.
  - No additional controls appear in the main tables. Robustness checks with controls are in Appendix D. The note to Table 2 says differences between rule-of-72 and exact future values are controlled for.

- **Proposed outcome metric (deliberative competence)**: d^M_{i,R,t} = −|r^c_{i,R,t} − r^s_{i,R,t}|, the negative absolute price-metric bias. num <- function(x) {
  x <- as.character(x)
  x <- gsub("[    ﻿]", " ", x, perl = TRUE)
  x <- trimws(x)
  v <- suppressWarnings(as.numeric(x))
  bad <- is.na(v) & !is.na(x) & x != ""
  if (any(bad)) {
    y <- x[bad]
    y <- ifelse(grepl(",", y) & !grepl("\\.", y), gsub(",", ".", y, fixed = TRUE),
                gsub(",", "", y, fixed = TRUE))
    r <- regexpr("-?[0-9]*\\.?[0-9]+", y, perl = TRUE)
    out <- rep(NA_real_, length(y))
    if (any(r > 0)) out[r > 0] <- suppressWarnings(as.numeric(regmatches(y, r)))
    v[bad] <- out
  }
  v
}

# Relaxed score-column detection: ^SC columns first, then other "score" columns.
score_cands <- function(d, label) {
  cs1 <- grep("^SC", names(d), value = TRUE, ignore.case = TRUE)
  cs2 <- setdiff(grep("score", names(d), value = TRUE, ignore.case = TRUE), cs1)
  cs <- c(cs1, cs2)
  keep <- character(0)
  for (c in cs) {
    x <- num(d[[c]])
    shr <- mean(is.finite(x))
    if (sum(is.finite(x)) == 0) { dg(label, "score col", c, "| no numeric values"); next }
    nd <- length(unique(x[is.finite(x)]))
    dg(label, "score col", c, "| finite share", round(shr, 3), "| min", min(x, na.rm = TRUE),
       "| max", max(x, na.rm = TRUE), "| distinct", nd)
    if (shr > 0.3 && min(x, na.rm = TRUE) >= 0 && nd >= 2) keep <- c(keep, c)
  }
  keep
}

multi_flag <- function(d, label) {
  sw <- grep("^switch[0-9]+$", names(d), value = TRUE, ignore.case = TRUE)
  if (length(sw) == 0) {
    dg(label, "no switch columns found")
    if ("excluded" %in% names(d)) return(num(d$excluded) %in% 1)
    return(rep(FALSE, nrow(d)))
  }
  S <- sapply(sw, function(c) num(d[[c]]))
  if (is.null(dim(S))) S <- matrix(S, nrow = nrow(d))

  vals <- unique(as.vector(S)); vals <- vals[is.finite(vals)]
  shr1 <- mean(mxs >= 1, na.rm = TRUE)
  dg(label, "switch cols:", length(sw), "| distinct values:", paste(sort(vals), collapse = " "),
     "| share any>=1:", round(shr1, 3))

  m
}

find_T_cols <- function(d) {
  tc <- paste0("T", 1:20)
  if (all(tc %in% names(d))) return(tc)
  alt <- grep("^(T|r|val|value|v|task)[_ ]?[0-9]+$", names(d), value = TRUE, ignore.case = TRUE)
  if (length(alt) == 20) {
    o <- order(num(gsub("[^0-9]", "", alt)))
    return(alt[o])
  }
  NULL
}

dc_regression <- function(D, arm, levels_) {
  n <- nrow(D)
  long <- data.frame(sid = rep(seq_len(n), times = ncol(D)),
                     arm = rep(arm, times = ncol(D)),
                     d = as.vector(D), stringsAsFactors = FALSE)
  long <- long[is.finite(long$d), ]
  for (l in levels_) long[[paste0("arm_", l)]] <- as.integer(long$arm == l)
  fml <- as.formula(paste("d ~ 0 +", paste(paste0("arm_", levels_), collapse = " + ")))
  m <- feols(fml, data = long, cluster = ~sid)
  print(summary(m))
  list(coef = coef(m), nobs = nobs(m))
}

Title: EVALUATING DELIBERATIVE COMPETENCE:
Methodology: - **Design / data**: Two randomized online experiments on Amazon Mechanical Turk (US residents, 18+). Experiment A (Apr–May 2014, 8 sessions, 504 subjects) has 4 between-subject arms: Control (index-fund video), Treatment (compound-interest video based on Malkiel & Ellis 2013, including the rule of 72), Substance-Only and Rhetoric-Only. Experiment B (Oct 2018, 2 sessions, 401 subjects; required ≥500 completed HITs and ≥98% approval) has 2 arms: Control (portfolio diversification) and Treatment (the compound-interest video split into 3 parts, plus 6 practice problems with individualized feedback). Each subject was in exactly one arm. Each experiment has 3 stages: education intervention → 10 pairs of valuation tasks → incentivized 10-question test (5 on compound interest, 5 on the control module). The two experiments are analyzed separately because their samples differ; they are not compared directly.
- **Valuation measurement**: Iterated multiple price lists (Andersen et al. 2006) with a $0.20 resolution give the immediate dollar equivalent of a reward R ∈ {$20, $18, $16, $14, $12} paid in t ∈ {36, 72} days (Table 2). Each reward is shown twice: in a simple frame ("We will pay you $R in t days") and in a complex frame (invest $a at X% daily interest, compounded daily). Task order is randomized at the subject level. Payment: with 75% probability one randomly chosen decision is paid, with 25% probability the test score is paid ($1 per correct answer). Everyone also gets a $10 completion fee.
- **Preprocessing**: Valuations are interval-coded, and the midpoint of the interval is used. Each valuation is normalized as r^f_{i,R,t} = r̃^f_{i,R,t}/R and expressed in percentage points (0–100, i.e. cents per future $1). This is a rescaling, not a standardization; coefficients are in percentage points of the future reward, and test scores are numbers of correct answers out of 5.
- **Sample restrictions**: Subjects who switched two or more times in any price list are dropped (49 of 504 in A, 53 of 401 in B), following Harrison et al. (2005). This leaves 803 subjects who respected monotonicity: 455 in Experiment A across all 4 arms, of which 215 are in Control+Treatment, and 348 in Experiment B. Attrition is reported (4 subjects in A; in B, 2 in Control and 9 in Treatment, a difference significant at 5%) but not adjusted for. Balance was checked with 68 F-tests on demographics (2 significant at 5%, 5 at 10%).
- **Conventional-metric regressions (OLS on treatment indicators, levels parameterization with no constant)**:
  - Table 4: test score (out of 5) on Control/Treatment dummies, one observation per subject (N = 215 in A, 348 in B). Columns 1–2 use compound-interest questions; columns 3–4 use control-module questions. Headline differences are 1.442 (SE 0.194) for A and 1.601 (0.143) for B.
  - Table 5: normalized complex-frame valuation r^c on treatment dummies, using all 10 tasks per subject (2,150 obs in A, 3,480 in B), with SEs clustered by subject. Columns 3–6 split by 72- and 36-day delay (1,075 / 1,740 obs). Headline Treatment–Control differences are 14.312 (3.431) for A and 15.134 (2.834) for B.
  - Table 6 (Experiment A, all 4 arms, 455 subjects): the dependent variables are the compound-interest score, the control-module score, the complex-frame valuation and the simple-frame valuation (4,550 obs), each regressed on the 4 arm dummies with SEs clustered by subject. It reports p-values for each arm's difference from Control.
  - No additional controls appear in the main tables. Robustness checks with controls are in Appendix D. The note to Table 2 says differences between rule-of-72 and exact future values are controlled for.
- **Distributional analysis**: Empirical CDFs of the valuation difference r^c − r^s for each task, by arm and experiment (Figure 3). Mass below 0 indicates exponential growth bias, and mass above 0 indicates overestimation.
- **Proposed outcome metric (deliberative competence)**: d^M_{i,R,t} = −|r^c_{i,R,t} − r^s_{i,R,t}|, the negative absolute price-metric bias. It is averaged over each subject's 10 tasks, then over subjects, and compared across treatment arms. A squared version is also mentioned. The excerpt is cut off before the results for this metric.

process <- function(d, label) {
  cat("====", label, "====\n")
  cat("rows:", nrow(d), " cols:", ncol(d), "\n")
  tcols <- grep("^T[0-9]+$", names(d), value = TRUE)
  tcols <- tcols[order(as.integer(sub("^T", "", tcols)))]
  if (length(tcols) < 20) {
    cat("Column names:\n"); print(names(d))
    stop(paste("Fewer than 20 T columns in", label))
  }
  tcols <- tcols[1:20]
  Tm <- colmat(d, tcols)
  cat("non-NA counts per T column:\n"); print(colSums(!is.na(Tm)))

  # treatment column: prefer exact 'treatment', must have 2..8 distinct nonempty values
  nonempty <- function(cc) { v <- trimws(as.character(d[[cc]])); sum(!is.na(v) & v != "") }
  nuniq <- function(cc) { v <- trimws(as.character(d[[cc]])); v <- v[!is.na(v) & v != ""]; length(unique(v)) }
  exact <- names(d)[tolower(names(d)) == "treatment"]
  cand <- unique(c(exact, grep("treat|condition", names(d), ignore.case = TRUE, value = TRUE)))
  cand <- cand[sapply(cand, function(cc) { k <- nuniq(cc); k >= 2 && k <= 8 })]
  if (length(cand) == 0) { print(names(d)); stop("no treatment column") }
  ex_ok <- intersect(exact, cand)
  if (length(ex_ok) > 0 && nonempty(ex_ok[1]) > 0) {
    trcol <- ex_ok[1]
  } else {
    ne <- sapply(cand, nonempty)
    trcol <- cand[which.max(ne)]
  }

  # score columns
  sccols <- grep("^SC0(_[0-9]+)?$", names(d), value = TRUE)
  if (length(sccols) == 0) sccols <- grep("^SC", names(d), value = TRUE)
  if (length(sccols) == 0) { print(names(d)); stop("no score columns") }
  sccols <- sort(sccols)
  S <- colmat(d, sccols)
  cat("non-NA counts per score column:\n"); print(colSums(!is.na(S)))
  S <- S[, colSums(!is.na(S)) > 0, drop = FALSE]
  if (ncol(S) == 0) stop("all score columns empty")
  if (ncol(S) >= 3) {
    for (j in seq_len(ncol(S))) {
      cc <- rowSums(is.na(S)) == 0
      if (sum(cc) > 0 && all(abs(S[cc, j] - rowSums(S[cc, -j, drop = FALSE])) < 1e-6)) {
        cat("dropping total score column:", colnames(S)[j], "\n")
        S <- S[, -j, drop = FALSE]
        break
      }
    }
  }
  if (ncol(S) > 2) S <- S[, 1:2, drop = FALSE]

  ids <- paste(d$batch_file, d$row_in_file, sep = "_")

  arm_raw <- trimws(as.character(d[[trcol]]))
  arm_ok <- !is.na(arm_raw) & arm_raw != ""
  tcnt <- rowSums(!is.na(Tm))
  sc_ok <- rowSums(!is.na(S)) > 0
  cat("treatment column:", trcol, " score columns:", paste(colnames(S), collapse = ","), "\n")
  cat("rows with arm:", sum(arm_ok), " rows with any score:", sum(sc_ok), "\n")
  cat("distribution of # nonmissing T among rows with arm:\n"); print(table(tcnt[arm_ok]))

  if (any(arm_ok & tcnt == 20)) {
    tmin <- 20
  } else if (any(arm_ok & tcnt > 0)) {
    tmin <- max(tcnt[arm_ok])
  } else {
    tmin <- NA
  }
  hasT <- !is.na(tmin)
  ok <- if (hasT) arm_ok & tcnt >= tmin else arm_ok & sc_ok
  cat("T threshold:", tmin, " complete rows:", sum(ok), "\n")

  # Exclusion of multiple switchers
  excl <- rep(NA, nrow(d))
  if ("excluded" %in% names(d)) {
    v <- tolower(trimws(as.character(d$excluded)))
    cat("excluded column values (complete rows):\n"); print(table(v[ok], useNA = "ifany"))
    excl <- ifelse(is.na(v) | v == "", NA, v %in% c("1", "true", "t", "yes", "1.0"))
  }
  swc <- grep("^switch[0-9]+$", names(d), ignore.case = TRUE, value = TRUE)
  swrule <- rep(NA, nrow(d))
  if (length(swc) > 0) {
    Sw <- colmat(d, swc)
    vals <- Sw[ok, , drop = FALSE]
    mxsw <- if (any(!is.na(vals))) max(vals, na.rm = TRUE) else NA
    cat("switch columns:", length(swc), " max switch value:", mxsw, "\n")
    if (!is.na(mxsw)) {
      if (mxsw <= 1) {
        swrule <- rowSums(Sw == 1, na.rm = TRUE) > 0
      } else {
        swrule <- rowSums(Sw >= 2, na.rm = TRUE) > 0
      }
      swrule[rowSums(!is.na(Sw)) == 0] <- NA
    }
    if (any(!is.na(excl[ok]))) {
      cat("agreement excluded vs switch rule:\n")
      print(table(excluded = excl[ok], swrule = swrule[ok], useNA = "ifany"))
    }
  }
  excl_final <- ifelse(!is.na(excl), excl, ifelse(!is.na(swrule), swrule, FALSE))
  cat("excluded among complete:", sum(excl_final[ok]), "\n")

  keep <- ok & !excl_final
  cat("kept:", sum(keep), "\n")
  print(table(arm_raw[keep]))
  if (sum(keep) == 0) stop(paste("no rows kept in", label))
  list(id = ids[keep], arm_raw = arm_raw[keep], S = S[keep, , drop = FALSE],
       Tm = Tm[keep, , drop = FALSE], hasT = hasT)
}

compute_dc <- function(Tm) {
  n <- nrow(Tm)
  M <- max(Tm, na.rm = TRUE)
  cat("valuation summary:\n"); print(summary(as.vector(Tm)))
  scale_type <- if (M <= 1.05) "fraction" else if (M <= 21) "dollars" else if (M <= 105) "percent" else "cents"
  cat("scale type:", scale_type, "\n")
  X <- Tm
  if (scale_type == "cents") X <- X / 100
  pairsA <- cbind(1:10, 11:20)
  pairsB <- cbind(seq(1, 19, 2), seq(2, 20, 2))
  paircor <- function(p) mean(sapply(1:10, function(k) suppressWarnings(cor(X[, p[k, 1]], X[, p[k, 2]], use = "complete.obs"))), na.rm = TRUE)
  if (scale_type %in% c("dollars", "cents")) {
    candR <- c(12, 14, 16, 18, 20)
    mx <- apply(X, 2, function(z) if (any(!is.na(z))) max(z, na.rm = TRUE) else NA)
    Rcol <- sapply(mx, function(m) if (is.na(m)) NA else candR[which.min(abs(candR - m))])
    cat("column maxima:\n"); print(round(mx, 2))
    cat("inferred R per column:\n"); print(Rcol)
    mA <- sum(Rcol[pairsA[, 1]] == Rcol[pairsA[, 2]], na.rm = TRUE)
    mB <- sum(Rcol[pairsB[, 1]] == Rcol[pairsB[, 2]], na.rm = TRUE)
    if (mB > mA) {
      pairs <- pairsB
    } else if (mA > mB) {
      pairs <- pairsA
    } else {
      pairs <- if (isTRUE(paircor(pairsB) > paircor(pairsA))) pairsB else pairsA
    }
    Rp <- pmax(Rcol[pairs[, 1]], Rcol[pairs[, 2]], na.rm = TRUE)
    cat("pairs used:\n"); print(pairs); cat("R per pair:", Rp, "\n")
    if (!all(table(factor(Rp, levels = candR)) == 2)) cat("WARNING: inferred R per pair not balanced\n")
    P1 <- sweep(X[, pairs[, 1], drop = FALSE], 2, Rp, "/") * 100
    P2 <- sweep(X[, pairs[, 2], drop = FALSE], 2, Rp, "/") * 100
  } else {
    if (scale_type == "fraction") X <- X * 100
    pairs <- if (isTRUE(paircor(pairsB) > paircor(pairsA))) pairsB else pairsA
    cat("pairs used:\n"); print(pairs)
    P1 <- X[, pairs[, 1], drop = FALSE]
    P2 <- X[, pairs[, 2], drop = FALSE]
  }
  -abs(P1 - P2)
}

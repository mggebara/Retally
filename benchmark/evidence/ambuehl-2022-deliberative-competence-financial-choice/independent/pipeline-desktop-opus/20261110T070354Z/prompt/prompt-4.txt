Title: EVALUATING DELIBERATIVE COMPETENCE:
Methodology: - **Design / data**: Two randomized online experiments on Amazon Mechanical Turk (US residents, 18+). Experiment A (Apr–May 2014, 8 sessions, 504 subjects) has 4 between-subject arms: Control (index-fund video), Treatment (compound-interest video based on Malkiel & Ellis 2013, including the rule of 72), Substance-Only and Rhetoric-Only. Experiment B (Oct 2018, 2 sessions, 401 subjects; required ≥500 completed HITs and ≥98% approval) has 2 arms: Control (portfolio diversification) and Treatment (the compound-interest video split into 3 parts, plus 6 practice problems with individualized feedback). Each subject was in exactly one arm. Each experiment has 3 stages: education intervention → 10 pairs of valuation tasks → incentivized 10-question test (5 on compound interest, 5 on the control module). The two experiments are analyzed separately because their samples differ; they are not compared directly.
- **Valuation measurement**: Iterated multiple price lists (Andersen et al. 2006) with a $0.20 resolution give the immediate dollar equivalent of a reward R ∈ {$20, $18, $16, $14, $12} paid in t ∈ {36, 72} days (Table 2). Each reward is shown twice: in a simple frame ("We will pay you $R in t days") and in a complex frame (invest $a at X% daily interest, compounded daily). Task order is randomized at the subject level. Payment: with 75% probability one randomly chosen decision is paid, with 25% probability the test score is paid ($1 per correct answer). Everyone also gets a $10 completion fee.
- **Preprocessing**: Valuations are interval-coded, and the midpoint of the interval is used. Each valuation is normalized as r^f_{i,R,t} = r̃^f_{i,R,t}/R and expressed in percentage points (0–100, i.e. cents per future $1). This is a rescaling, not a standardization; coefficients are in percentage points of the future reward, and test scores are numbers of correct answers out of 5.
- **Sample restrictions**: Subjects who switched two or more times in any price list are dropped (49 of 504 in A, 53 of 401 in B), following Harrison et al. (2005). This leaves 803 subjects who respected monotonicity: 455 in Experiment A across all 4 arms, of which 215 are in Control+Treatment, and 348 in Experiment B. Attrition is reported (4 subjects in A; in B, 2 in Control and 9 in Treatment, a difference significant at 5%) but not adjusted for. Balance was checked with 68 F-tests on demographics (2 significant at 5%, 5 at 10%).
- **Conventional-metric regressions (OLS on treatment indicators, levels parameterization with no constant)**:
  - Table 4: test score (out of 5) on Control/Treatment dummies, one observation per subject (N = 215 in A, 348 in B). Columns 1–2 use compound-interest questions; columns 3–4 use control-module questions. Headline differences are 1.442 (SE 0.194) for A and 1.601 (0.143) for B.
  - Table 5: normalized complex-frame valuation r^c on treatment dummies, using all 10 tasks per subject (2,150 obs in A, 3,480 in B), with SEs clustered by subject. Columns 3–6 split by 72- and 36-day delay (1,075 / 1,740 obs). Headline Treatment–Control differences are 14.312 (3.431) for A and 15.134 (2.834) for B.
  - Table 6 (Experiment A, all 4 arms, 455 subjects): the dependent variables are the compound-interest score, the control-module score, the complex-frame valuation and the simple-frame valuation (4,550 obs), each regressed on the 4 arm dummies with SEs clustered by subject. It reports p-values for each arm's difference from Control.
  - No additional controls appear in the main tables. Robustness checks with controls are in Appendix D. The note to Table 2 says differences between rule-of-72 and exact future values are controlled for.
- **Distributional analysis**: Empirical CDFs of the valuation difference r^c − r^s for each task, by arm and experiment (Figure 3). Mass below 0 indicates exponential growth bias, and mass above 0 indicates overestimation.
- **Proposed outcome metric (deliberative competence)**: d^M_{i,R,t} = −|r^c_{i,R,t} − r^s_{i,R,t}|, the negative absolute price-metric bias. It is averaged over each subject's 10 tasks, then over subjects, and compared across treatment arms. A squared version is also mentioned. The excerpt is cut off before the results for this metric.
- **Inference**: OLS, with conventional SEs for the subject-level test-score regressions and SEs clustered by subject for task-level valuation regressions. Significance stars are at 1%, 5% and 10%. No train/test split or cross-validation, and no ML hyperparameters (not applicable).

find_arm_col <- function(d, n_arms) {
  cs <- grep("treat|condition|group|arm", names(d), value = TRUE, ignore.case = TRUE)
  cs <- c(intersect("treatment", cs), setdiff(cs, "treatment"))
  info <- list()
  for (cc in cs) {
    v <- d[[cc]]; v <- v[!is.na(v) & v != ""]
    nu <- length(unique(v))
    tb <- head(sort(table(v), decreasing = TRUE), 10)
    cat(sprintf("  arm candidate %-15s n=%d nuniq=%d top: %s\n", cc, length(v), nu,
                paste(substr(names(tb), 1, 30), tb, sep = ":", collapse = " | ")))
    info[[cc]] <- nu
  }
  for (cc in cs) if (info[[cc]] == n_arms) return(cc)
  # fallback: prefer 'treatment' column (or first candidate) with at least 2 distinct values
  for (cc in cs) if (info[[cc]] >= 2 && info[[cc]] <= 50) return(cc)
  NA_character_
}

clean_arm_raw <- function(raw, n_arms) {
  raw <- as.character(raw)
  raw[!is.na(raw) & raw == ""] <- NA
  v <- raw[!is.na(raw)]
  if (length(unique(v)) > n_arms) {
    keepv <- names(head(sort(table(v), decreasing = TRUE), n_arms))
    cat("Arm column has", length(unique(v)), "values; keeping the", n_arms, "most frequent:",
        paste(keepv, collapse = ", "), "\n")
    raw[!(raw %in% keepv)] <- NA
  }
  raw
}

is_small_score <- function(d, cc) {
  x <- num(d[[cc]])
  any(!is.na(x)) && max(x, na.rm = TRUE) <= 5
}

filter_scores <- function(d, cs) {
  if (length(cs) == 0) return(character(0))
  cs[vapply(cs, function(cc) is_small_score(d, cc), logical(1))]
}

find_scores <- function(d) {
  if (all(c("SC0_0", "SC0_1") %in% names(d))) return(c("SC0_0", "SC0_1"))
  cs <- filter_scores(d, grep("^SC", names(d), value = TRUE, ignore.case = TRUE))

  cs <- filter_scores(d, grep("score", names(d), value = TRUE, ignore.case = TRUE))
  if (length(cs) >= 2) return(cs[1:2])

  c(NA_character_, NA_character_)
}

label_arms <- function(raw, comp, four) {
  u <- unique(raw[!is.na(raw) & raw != ""])
  nu <- num(u)
  u <- if (all(!is.na(nu))) u[order(nu)] else sort(u)
  lab <- setNames(rep(NA_character_, length(u)), u)
  lu <- tolower(u)
  if (any(grepl("[a-z]", lu))) {
    lab[grepl("contr|index|divers|base", lu)] <- "Control"
    lab[is.na(lab) & grepl("subst", lu)] <- "SubstanceOnly"
    lab[is.na(lab) & grepl("rhet", lu)] <- "RhetoricOnly"
    lab[is.na(lab) & grepl("treat|full|compound|feedback|practice", lu)] <- "Treatment"
  }
  default <- if (four) c("Control", "Treatment", "SubstanceOnly", "RhetoricOnly") else c("Control", "Treatment")
  if (any(is.na(lab)) || any(duplicated(lab))) lab[] <- default[seq_along(u)]
  arm <- unname(lab[raw])
  # data check: Control should have the lowest compound-interest score
  cat("Arm mapping:", paste(names(lab), lab, sep = "->", collapse = ", "), "\n")
  if (any(!is.na(comp))) {
    m <- tapply(comp, arm, mean, na.rm = TRUE)
    cat("Mean compounding score by arm:", paste(names(m), round(m, 3), collapse = ", "), "\n")
    m <- m[!is.na(m)]
    if (length(m) > 0) {
      lowest <- names(m)[which.min(m)]
      if (lowest != "Control" && "Control" %in% names(m)) {
        cat("WARNING: arm", lowest, "has lowest compounding score; swapping its label with Control\n")
        a2 <- arm
        a2[arm == lowest] <- "Control"; a2[arm == "Control"] <- lowest
        arm <- a2
      }
    }
  }
  arm
}

multi_switch <- function(d) {
  sc <- grep("^switch[0-9]+$", names(d), value = TRUE, ignore.case = TRUE)
  if (length(sc) > 0) {
    S <- sapply(sc, function(cc) num(d[[cc]]))
    if (is.null(dim(S))) S <- matrix(S, nrow = nrow(d))
    mx <- suppressWarnings(max(S, na.rm = TRUE))
    if (is.finite(mx) && mx >= 2) {
      ms <- apply(S, 1, function(r) any(r >= 2, na.rm = TRUE))
      cat("Multiple switchers from switch counts (>=2):", sum(ms), "\n")
      return(ms)
    }
    if (is.finite(mx) && mx == 1) {
      ms <- apply(S, 1, function(r) any(r == 1, na.rm = TRUE))
      if (mean(ms) < 0.5) {
        cat("Multiple switchers from 0/1 switch flags:", sum(ms), "\n")
        return(ms)
      }
    }
  }
  if ("excluded" %in% names(d)) {
    ex <- num(d$excluded)
    ms <- !is.na(ex) & ex == 1
    cat("Using 'excluded' column as multiple-switch flag:", sum(ms), "\n")
    return(ms)
  }
  cat("WARNING: no multiple-switch information found\n")
  rep(FALSE, nrow(d))
}

get_vals <- function(d) {
  tc <- paste0("T", 1:20)
  if (!all(tc %in% names(d))) { cat("WARNING: T1..T20 not found\n"); return(NULL) }
  V <- sapply(tc, function(cc) num(d[[cc]]))
  ok <- rowSums(!is.na(V)) == 20
  if (sum(ok) == 0) { cat("WARNING: T1..T20 are not numeric valuations\n"); return(NULL) }
  perm <- mean(apply(V[ok, , drop = FALSE], 1, function(r) all(sort(r) == 1:20)))
  cat("Share of complete rows where T1..T20 is a permutation of 1:20:", perm, "\n")
  if (perm > 0.8) { cat("WARNING: T1..T20 look like task order, not valuations\n"); return(NULL) }
  V
}

build_dc <- function(V) {
  mx <- apply(V, 2, max, na.rm = TRUE)
  cat("Column max of valuations:", round(mx, 2), "\n")
  if (max(mx) <= 21) {
    Rs <- c(12, 14, 16, 18, 20)
    R <- sapply(mx, function(m) Rs[which.min(abs(Rs - m))])
    P <- sweep(V, 2, R, "/") * 100
  } else {
    R <- rep(NA, 20)
    P <- V
  }
  cat("Estimated R per column:", R, "\n")
  sds <- apply(P, 2, sd, na.rm = TRUE)
  mns <- colMeans(P, na.rm = TRUE)
  cx <- rank(-sds, ties.method = "first") <= 10
  cat("Column SDs:", round(sds, 2), "\n")
  cat("Column means:", round(mns, 2), "\n")
  cat("Complex-frame columns (high SD):", which(cx), "\n")
  si <- which(!cx); ci <- which(cx)
  Rs_ <- ifelse(is.na(R), 0, R)
  si <- si[order(-Rs_[si], -mns[si])]
  ci <- ci[order(-Rs_[ci], -mns[ci])]
  cat("Pairs (simple, complex):", paste0("(", si, ",", ci, ")", collapse = " "), "\n")
  if (any(Rs_[si] != Rs_[ci])) cat("WARNING: paired columns differ in R\n")
  -abs(P[, ci, drop = FALSE] - P[, si, drop = FALSE])
}

Title: American Political Science Review (2023) 117, 1, 318–324
Methodology: - **Data and unit of analysis**: An original party-level dataset on women's share of each party's parliamentary delegation (125 parties, 20 Western democracies, 1996–2017) is merged with CSES surveys (81 election studies). The unit is the directed party dyad (i, j, t). Each pair enters twice, once as i's partisans rating j and once as j's partisans rating i. The estimation sample is 1,842 directed dyads.
- **Dependent variable**: [party i's supporters' evaluations of out-party j (t)], the mean 0–10 CSES feeling-thermometer score (0 = strongly dislike, 10 = strongly like) that party i's partisans give out-party j in the election survey of year t. Partisans are respondents who say they feel "close" or "a little closer" to party i. The DV's standard deviation is 1.54.
- **Key regressor**: [out-party j's proportion of women MPs (t – 1)], j's parliamentary gender composition lagged one year before the survey (e.g., 2012 data for the 2013 German election). It is measured as a raw proportion from 0 (all men) to 1 (all women), not standardised; mean 0.29, SD 0.16. The headline coefficient (+1.73) is the thermometer change from a 0 to a 1 share. Moving from mean −1 SD (0.13) to +1 SD (0.45) gives a gain of about 0.55.
- **Controls (full model, Table 1 col. 2)**: [elite right–left distance i, j (t)] is the absolute difference in CMP Left–Right (rile, −100 to +100) manifesto scores in the current election. **It is standardised** (raw mean 22.4, SD 17.6), so its coefficient is per one SD. [i, j are coalition partners (t)] is a dummy for governing coalition partners at t. [i, j are opposition partners (t)] is a dummy for both being in opposition. The baseline is one governing party and one opposition party. Specification is linear in levels: Thermometer_ijt = β·WomenShare_j,t−1 + γ1·RLdist_std + γ2·Coalition + γ3·Opposition + FE + ε.
- **Estimator, fixed effects, SEs**: OLS with country-year (election) fixed effects. The text says country-year; the Table 1 row reads "Country and year fixed effects: YES". So estimates come from within-election comparisons across out-parties. Robust standard errors are clustered by election (country-year). Significance is two-tailed (*p<0.05, **p<0.01).
- **Sample restrictions**: Only dyads where both parties i and j had at least 4 MPs in the year before the election survey. Smaller parties are dropped as less consequential and because few respondents identify with them. Each dyad also needs CMP and thermometer data.
- **Models and headline results (Table 1)**: Col. 1 is bivariate (women share only, with FE): 1.89** (0.43), adj. R² 0.15, N=1,842. Col. 2 is the full model: women share 1.73** (0.52); RL distance −0.60** (0.09); coalition partners 0.94** (0.25); opposition partners 0.37** (0.11); adj. R² 0.31; N=1,842. Col. 3 re-computes the DV from women respondents only: 2.10** (0.53), −0.62**, 0.94**, 0.36**; N=1,836; adj. R² 0.31. Col. 4 uses men respondents only: 1.13* (0.50), −0.66**, 0.96**, 0.35**; N=1,833; adj. R² 0.30.
- **Robustness (appendix)**: The appendix covers smaller parties included (S2), out-party family controls (S3), early vs. late periods (S4), in-party women's share (S5), electoral proportionality (S6), nonlinearity past parity (S7), and out-parties with women vs. men leaders (S8). num <- function(x) suppressWarnings(as.numeric(as.character(x)))

find_women_col <- function(df) {
  nm <- names(df)
  cand <- nm[grepl("wom|female|fem|gender_prop|prop_w|pct_w|per_w", nm, ignore.case = TRUE) &
               grepl("^to_|_to_|_to$|out", nm, ignore.case = TRUE)]
  if (length(cand) == 0) {
    cand <- nm[grepl("wom|female|fem", nm, ignore.case = TRUE) &
                 !grepl("^from_", nm, ignore.case = TRUE)]
  }
  cand <- setdiff(cand, c("gender"))
  if (length(cand) == 0) stop("No women-share column found")
  score <- sapply(cand, function(v) {
    x <- num(df[[v]])
    if (all(is.na(x))) return(-Inf)
    m <- mean(x, na.rm = TRUE)
    if (m > 1.5) m <- m / 100
    s <- -abs(m - 0.29) * 10
    if (grepl("lag|prior|t_1|t1|prev|lag1", v, ignore.case = TRUE)) s <- s + 2
    if (grepl("prop|share|pct|per", v, ignore.case = TRUE)) s <- s + 0.5
    if (grepl("leader", v, ignore.case = TRUE)) s <- s - 5
    if (grepl("number|num|count|_n$", v, ignore.case = TRUE) && mean(x, na.rm = TRUE) > 1.5) s <- s - 3
    s
  })
  cat("Women-share candidates and scores:\n"); print(score)
  names(score)[which.max(score)]
}

pick_dv <- function(df) {
  nm <- names(df)
  for (v in c("party_like", "thermometer_score", "thermometer", "like", "mean_like")) {
    if (v %in% nm) return(v)
  }
  if ("party_dislike" %in% nm) return("party_dislike")
  if ("dislike" %in% nm) return("dislike")
  stop("No DV found")
}

prep <- function(df) {
  wcol <- find_women_col(df)
  cat("Using women-share column:", wcol, "\n")
  w <- num(df[[wcol]])
  if (mean(w, na.rm = TRUE) > 1.5) w <- w / 100
  df$women_share <- w
  dv <- pick_dv(df)
  cat("Using DV column:", dv, "\n")
  y <- num(df[[dv]])
  if (dv %in% c("party_dislike", "dislike")) y <- 10 - y
  df$therm <- y
  df$rl_raw <- num(df$rile_distance)
  df$coal <- num(df$govern_together)
  df$opp <- num(df$opposition_together)
  df$from_mp <- num(df$from_mp_number)
  df$to_mp <- num(df$to_mp_number)
  df$election <- paste(df$country, df$year, sep = "_")
  df
}

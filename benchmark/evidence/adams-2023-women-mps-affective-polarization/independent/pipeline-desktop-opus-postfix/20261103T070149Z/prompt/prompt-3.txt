## Paper
Title: American Political Science Review (2023) 117, 1, 318–324
Methodology: - **Data and unit of analysis**: An original party-level dataset on women's share of each party's parliamentary delegation (125 parties, 20 Western democracies, 1996–2017) is merged with CSES surveys (81 election studies). The unit is the directed party dyad (i, j, t). Each pair enters twice: i's partisans rating j, and j's partisans rating i. N = 1,842 directed dyads in the main models.
- **Dependent variable**: [party i's supporters' evaluations of out-party j (t)] is the mean 0–10 CSES feeling-thermometer score (0 = strongly dislike, 10 = strongly like) that party i's partisans give out-party j in the election survey in year t. The DV has SD 1.54. Partisans are respondents who say they feel "close" or "a little closer" to a party, from the two-step CSES party-ID question.
- **Key regressor**: [out-party j's proportion of women MPs (t – 1)] is the share of j's MPs who are women, measured in the year before the survey (e.g. 2012 data for the 2013 German election). It runs from 0 (all men) to 1 (all women) and is not standardised: mean 0.29, SD 0.16. The coefficient is the change in thermometer points from 0% to 100% women MPs.
- **Estimating equation (Table 1, col. 2, preferred)**: OLS, linear in levels: Eval_ijt = β·WomenShare_j,t−1 + γ1·RLdist_ijt + γ2·CoalitionPartners_ijt + γ3·OppositionPartners_ijt + FE + ε. Controls:
  - **[elite right–left distance i, j (t)]**: absolute CMP right–left (rile) distance between i and j in the current election, standardised to SD = 1 (raw mean 22.4, SD 17.6 on the −100…+100 scale).
  - **[i, j are coalition partners (t)]**: dummy, both parties govern together at time t.
  - **[i, j are opposition partners (t)]**: dummy, both parties are in opposition. The baseline is one governing and one opposition party.
- **Fixed effects and standard errors**:
  - **Fixed effects**: country-year (election) fixed effects. Table 1 labels them "Country and year fixed effects", but the text says country-year, so estimates use within-election variation across out-parties.
  - **Standard errors**: robust, clustered by election (country-year survey).
  - **Significance**: two-tailed tests, * p<0.05, ** p<0.01.
- **Sample restrictions**: The sample keeps only dyads where both i and j had at least 4 MPs in the year before the survey. Smaller parties are dropped: they matter less and few respondents identify with them, so their means are noisy. Dyads need non-missing CMP positions and partisan mean ratings. There is no train/test split or cross-validation; this is a pure inferential regression.

find_women_share <- function(df) {
  nm <- names(df)
  cand <- nm[grepl('wom|fem', nm, ignore.case = TRUE)]
  cand <- cand[sapply(cand, function(v) is.numeric(df[[v]]))]
  cand <- cand[!grepl('^from|_from', cand, ignore.case = TRUE)]
  cand <- cand[!grepl('leader|lead|head|chair|resp|gender$', cand, ignore.case = TRUE)]
  # drop binary dummies
  cand <- cand[sapply(cand, function(v) {
    u <- unique(na.omit(df[[v]])); length(u) > 2
  })]
  if (length(cand) == 0) stop('No women-share column found')
  score <- sapply(cand, function(v) {
    s <- 0
    if (grepl('^to_|_to_|_to$|^to', v, ignore.case = TRUE)) s <- s + 8
    if (grepl('mp|seat|parl|legis|deleg', v, ignore.case = TRUE)) s <- s + 4
    if (grepl('prop|share|pct|perc|per', v, ignore.case = TRUE)) s <- s + 2
    if (grepl('lag|t1|t_1|prior|prev', v, ignore.case = TRUE)) s <- s + 1
    if (grepl('num|count|n_|number', v, ignore.case = TRUE)) s <- s - 1
    s
  })
  v <- cand[order(-score)][1]
  x <- df[[v]]
  mx <- suppressWarnings(max(x, na.rm = TRUE))
  if (is.finite(mx) && mx > 1.5) {
    if (grepl('num|count|n_|number', v, ignore.case = TRUE) && 'to_mp_number' %in% names(df)) {
      x <- x / df$to_mp_number
    } else {
      x <- x / 100
    }
  }
  message('Women-share candidates: ', paste(cand, collapse = ', '))
  message('Women-share variable used: ', v)
  x
}

find_dv <- function(df) {
  for (v in c('party_like', 'thermometer', 'thermometer_score', 'like')) {
    if (v %in% names(df) && is.numeric(df[[v]])) return(df[[v]])
  }
  if ('dislike' %in% names(df)) return(10 - df$dislike)
  stop('No DV found')
}

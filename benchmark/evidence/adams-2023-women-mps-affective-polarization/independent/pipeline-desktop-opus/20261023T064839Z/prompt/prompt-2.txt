Methodology: - **Data and unit of analysis**: An original party-level dataset on women's share of each party's parliamentary delegation (125 parties, 20 Western democracies, 1996–2017) is merged with CSES surveys (81 election studies). The unit is the directed party dyad (i, j, t). Each pair enters twice, once as i's partisans rating j and once as j's partisans rating i. The estimation sample is 1,842 directed dyads.
- **Dependent variable**: [party i's supporters' evaluations of out-party j (t)], the mean 0–10 CSES feeling-thermometer score (0 = strongly dislike, 10 = strongly like) that party i's partisans give out-party j in the election survey of year t. Partisans are respondents who say they feel "close" or "a little closer" to party i. The DV's standard deviation is 1.54.
- **Key regressor**: [out-party j's proportion of women MPs (t – 1)], j's parliamentary gender composition lagged one year before the survey (e.g., 2012 data for the 2013 German election). It is measured as a raw proportion from 0 (all men) to 1 (all women), not standardised; mean 0.29, SD 0.16. The headline coefficient (+1.73) is the thermometer change from a 0 to a 1 share. Moving from mean −1 SD (0.13) to +1 SD (0.45) gives a gain of about 0.55.

[i, j are coalition partners (t)] is a dummy for governing coalition partners at t. [i, j are opposition partners (t)] is a dummy for both being in opposition. The baseline is one governing party and one opposition party. Specification is linear in levels: Thermometer_ijt = β·WomenShare_j,t−1 + γ1·RLdist_std + γ2·Coalition + γ3·Opposition + FE + ε.

find_women_var <- function(df) {
  nm <- names(df)
  cand <- nm[grepl("wom|fem", nm, ignore.case = TRUE)]
  to_cand <- cand[grepl("^to_|_to_|_to$|^to", cand, ignore.case = TRUE)]
  if (length(to_cand) == 0) to_cand <- cand[!grepl("^from", cand, ignore.case = TRUE)]
  if (length(to_cand) == 0) return(NA_character_)
  # keep numeric
  to_cand <- to_cand[sapply(to_cand, function(v) is.numeric(df[[v]]))]
  if (length(to_cand) == 0) return(NA_character_)
  # exclude counts / leader dummies if possible
  pref <- to_cand[grepl("lag|t1|t_1|prior|prev", to_cand, ignore.case = TRUE)]
  pool <- if (length(pref) > 0) pref else to_cand
  pref2 <- pool[grepl("prop|share|pct|perc|per", pool, ignore.case = TRUE)]
  if (length(pref2) > 0) pool <- pref2
  notlead <- pool[!grepl("leader|number|count|num", pool, ignore.case = TRUE)]
  if (length(notlead) > 0) pool <- notlead
  # choose the one whose values look like a proportion (most distinct values)
  nd <- sapply(pool, function(v) length(unique(na.omit(df[[v]]))))
  pool[which.max(nd)]
}

find_dv <- function(df) {
  nm <- names(df)
  for (v in c("party_like", "thermometer", "thermometer_score", "like")) {
    if (v %in% nm && is.numeric(df[[v]])) return(v)
  }
  NA_character_
}

prep <- function(df, wvar, dv) {
  df$women_j <- as.numeric(df[[wvar]])
  if (max(df$women_j, na.rm = TRUE) > 1.5) df$women_j <- df$women_j / 100
  df$dv <- as.numeric(df[[dv]])
  df$rl_raw <- abs(as.numeric(df$rile_distance))
  df$coal <- as.numeric(df$govern_together)
  df$opp <- as.numeric(df$opposition_together)
  df$cy <- paste(df$country, df$year, sep = "_")
  keep <- !is.na(df$to_mp_number) & !is.na(df$from_mp_number) &
    as.numeric(df$to_mp_number) >= 4 & as.numeric(df$from_mp_number) >= 4 &
    !is.na(df$dv) & !is.na(df$women_j) & !is.na(df$rl_raw) &
    !is.na(df$coal) & !is.na(df$opp)
  df <- df[keep, ]
  df$rl_std <- (df$rl_raw - mean(df$rl_raw)) / sd(df$rl_raw)
  df
}

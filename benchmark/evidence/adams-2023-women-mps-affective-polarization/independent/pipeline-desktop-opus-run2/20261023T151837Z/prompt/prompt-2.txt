## Paper
Title: American Political Science Review (2023) 117, 1, 318–324
Methodology: - **Data and unit of analysis**: The authors combine an original party-level dataset on women's share of parliamentary seats with CSES survey data. It covers 20 Western democracies, 81 election surveys from 1996 to 2017 and 125 parties. The unit is the directed party dyad (i, j, t). Each party pair enters twice: once for i's partisans rating j, and once for j's partisans rating i. Partisans are respondents who say they are "close" or "a little closer" to party i.
- **Dependent variable**: [party i's supporters' evaluations of out-party j (t)]. This is the mean 0–10 CSES feeling-thermometer rating that party i's partisans give out-party j in the election survey of year t (0 = strongly dislike, 10 = strongly like). Its SD is 1.54. The model is linear in levels, with no logs.
- **Key regressor**: [out-party j's proportion of women MPs (t – 1)]. This is the share of j's parliamentary delegation who are women, lagged one year before the survey and scaled 0–1 in raw proportion units, not standardised (mean 0.29, SD 0.16). The headline coefficient is therefore the change in thermometer points from moving 0 → 1. Table 1, column 2 reports +1.73 (SE 0.52); from −1 SD to +1 SD (0.13 → 0.45) the predicted gain is about 0.55.
- **Controls (full model, Table 1 col. 2)**:
  - [elite right–left distance i, j (t)]: the absolute distance between parties i and j on the CMP left–right (rile) score of the current manifesto. Only this control is standardised (z-score; raw mean 22.4, SD 17.6).
  - [i, j are coalition partners (t)]: a dummy for i and j governing together at t.
  - [i, j are opposition partners (t)]: a dummy for both i and j being in opposition at t.
  - The omitted category is a pair with one governing party and one opposition party.
- **Fixed effects and estimator**: OLS with country-year (election) fixed effects, so estimates come from within-election comparisons. Robust standard errors are clustered by election (country-year). Significance uses two-tailed tests at *p < 0.05 and **p < 0.01.
- **Sample restriction**: Only dyads where both parties had at least 4 MPs in the year before the survey are kept. This gives N = 1,842 directed dyads in columns 1 and 2. Column 1 regresses the DV on women's share alone plus FE (coefficient 1.89, SE 0.43, adj. R² 0.15). Column 2 adds the controls (adj. R² 0.31).
- **Subgroup models**: The full model is re-estimated with the DV built only from women partisans (col. 3: N = 1,836, coefficient 2.10, SE 0.53) and only from men partisans (col. 4: N = 1,833, coefficient 1.13, SE 0.50).
- **Robustness checks (appendix)**:
  - including parties with fewer than 4 MPs (S2)
  - controls for out-party family (S3)
  - early vs. late periods (S4)
  - in-party women's share (S5)
  - electoral-system proportionality (S6)
  - non-linearity past parity (S7)
  - out-parties led by women vs. men (S8)
  - country FE instead of country-year FE (S9/S10)
  - a stacked individual-level dataset with individual FE (S11)
- **Evaluation**: There is no train/test split or cross-validation. Inference rests on coefficient size, clustered SEs and p-values, and the paper reports adjusted R².

is_thermo <- function(x) {
  x <- suppressWarnings(as.numeric(strip(x)))
  x <- x[!is.na(x)]
  if (length(x) < 50) return(FALSE)
  if (min(x) < 0 || max(x) > 10) return(FALSE)
  if (length(unique(x)) < 20) return(FALSE)
  mean(abs(x - round(x)) > 1e-8) > 0.3
}
find_dv <- function(df) {
  nm <- names(df)
  pri <- c(
    nm[grepl("therm|evaluat|feeling", nm, ignore.case = TRUE)],
    nm[tolower(nm) %in% c("like", "mean_like", "like_score", "avg_like")],
    nm[tolower(nm) %in% c("dislike", "mean_dislike")],
    nm[grepl("like", nm, ignore.case = TRUE) & !grepl("dislike", nm, ignore.case = TRUE)],
    nm[grepl("dislike", nm, ignore.case = TRUE)]
  )
  pri <- unique(pri)
  for (v in pri) {
    if (is_thermo(df[[v]])) {
      flip <- grepl("dislike", v, ignore.case = TRUE)
      return(list(var = v, flip = flip))
    }
  }
  stop("No DV found")
}

# ---- Women share detection ----
find_women <- function(df) {
  nm <- names(df)
  cand <- nm[grepl("wom|fem", nm, ignore.case = TRUE) & !grepl("^from|_from", nm, ignore.case = TRUE)]
  cand <- cand[!grepl("lead|chair|vote|respond|partisan", cand, ignore.case = TRUE)]
  if (length(cand) == 0) {
    cand <- nm[grepl("^to_.*(prop|share|pct|perc)", nm, ignore.case = TRUE)]
  }
  if (length(cand) == 0) stop("No women share variable found")
  score <- function(v) {
    s <- 0
    if (grepl("^to", v, ignore.case = TRUE)) s <- s + 4
    if (grepl("lag", v, ignore.case = TRUE)) s <- s + 2
    if (grepl("prop|share|pct|perc|percent", v, ignore.case = TRUE)) s <- s + 1
    if (grepl("leader|lead", v, ignore.case = TRUE)) s <- s - 10
    s
  }
  cand <- cand[order(-sapply(cand, score))]
  for (v in cand) {
    x <- suppressWarnings(as.numeric(strip(df[[v]])))
    if (all(is.na(x))) next
    if (length(unique(na.omit(x))) < 5) next
    return(v)
  }
  stop("No usable women share variable")
}

women_share <- function(df, v) {
  x <- suppressWarnings(as.numeric(strip(df[[v]])))
  mx <- max(x, na.rm = TRUE)
  if (mx <= 1.0001) return(x)
  isint <- all(abs(x - round(x)) < 1e-8, na.rm = TRUE)
  if (isint && "to_mp_number" %in% names(df)) {
    mp <- suppressWarnings(as.numeric(strip(df$to_mp_number)))
    if (all(x <= mp, na.rm = TRUE)) return(x / mp)
  }
  if (mx <= 100) return(x / 100)
  x
}

gender_split <- function(g) {
  gv <- g$gender
  labs <- attr(gv, "labels")
  if (!is.null(labs)) {
    fem_codes <- labs[grepl("fem|wom", names(labs), ignore.case = TRUE)]
    if (length(fem_codes) > 0) return(as.numeric(strip(gv)) %in% as.numeric(fem_codes))
  }
  if (is.factor(gv) || is.character(gv)) {
    s <- tolower(as.character(gv))
    return(grepl("^f|wom", s))
  }
  x <- as.numeric(strip(gv))
  u <- sort(unique(na.omit(x)))
  if (all(u %in% c(1, 2))) return(x == 2)
  if (all(u %in% c(0, 1))) return(x == 1)
  x == max(u)
}
